## 1. 目标与背景

**一句话目标**:注册一律创建推荐官身份(裸账号概念退役);商家身份唯一来源=治理台「初始化商家账号」;登录/注册表单彻底移除身份单选,登录按账号已有身份自动落地。

**已定案的关键决策(执行期不得更改)**:

| # | 决策 | 理由 |
|---|---|---|
| D1 | 注册即推荐官:注册事务内一律创建 recommender 身份档案(org null);`RegisterRequest` 删除 `initialIdentity` 组件(旧客户端多发的未知字段 Jackson 默认忽略,不报错) | 「注册默认都是推荐官」;裸账号概念退役;initialIdentity 已无消费方 |
| D2 | 商家身份唯一来源=治理台:`POST /api/me/identities` 对 type=merchant 一律 403;type=recommender 仅在账号身份档案数为 0 且无组织归属时放行(存量裸账号补开,条件见 D6),其余 409 | 「不支持商家注册」必须连自助开通口子一起关死,否则前端编排层还能开商家 |
| D3 | 登录/注册表单彻底移除身份单选(`withIdentityChoice` prop 整体删除,不搞「双身份账号才显示」的分支);落地规则=既有默认激活逻辑**原样保留**(商家身份优先/服务端已激活侧优先);存量双身份账号保留工作台切侧 | 自动落地后「选错身份」类缺陷源头消失;默认激活逻辑已覆盖推荐官账号/商家账号/双身份账号全部三类 |
| D4 | 治理台初始化商家账号=建账号+商家身份+一次性初始密码;`account_flag.must_change_password=true` 复用 #48 旁表,首登走既有 /first-password 强制改密;商家主体/KYB 仍由商家登录后自建(「创建你的商家主体」引导区保留) | 「商家账号由后台管理去初始化」的最小充分集;主体名等经营信息管理员不该代填 |
| D5 | 仅全新邮箱:初始化接口遇已注册邮箱 → 409;既有账号一律不可加开商家身份(**双向收紧**:商家账号也不得自助加开推荐官,即 POST /me/identities 对已有任何档案的账号一律 409) | 用户拍板;身份=账号类型,一刀切最清晰 |
| D6 | 存量全部保留(grandfather):既有商家/双身份/裸账号零迁移零清理;裸账号登录时由前端兜底自动补开推荐官——条件=身份档案数为 0 **且**无任何门店范围 **且**无任何组织归属(挡住主体子账号/池成员,他们保持既有商家视角) | 零数据订正风险;组织归属检查防止给子账号误开推荐官档案 |
| D7 | 零 Flyway 迁移:identity_profile/account_flag 均既有表;app_users 是 database-bootstrap 管的共享表,identity 迁移不得引用其 DDL(V42 注释铁律),运行时 INSERT 可以(RegisterController 先例) | 存量不动+复用既有表 |
| D8 | 前端激活竞态机制整体删除:claimActivation/releaseActivationClaim/initialActivationFinalize/activationClaimed(登录显式选择消失后,布局账号 watch 的默认激活成为唯一写入者,竞态源头不存在);loadAccountIdentity 的默认激活与 serverActivatedSide 优先逻辑原样保留 | 死代码不留守;唯一写入者模型天然无赛跑 |
| D9 | switchSide 删「激活 409 → 自动 openIdentity 重试」回退(自助开口已关,回退必败);对侧未开通时切侧入口隐藏/禁用;深链 `?side=` 对未开通侧回落本侧 | 回退分支成死代码;避免用户点切侧才收到 403 |
| D10 | 治理台建号 outbox 只发 IdentityOpened(merchant);**不发** UserRegistered、**不送** 3 积分注册赠礼 | UserRegistered 语义=自助注册(下游新用户统计/营销);平台初始化不该触发 |

## 2. 范围

**范围内(明确交付)**:
- 卡 A:注册默认推荐官 + POST /me/identities 收紧 + identity-service IT 重写
- 卡 B:`POST /api/admin/merchant-accounts` 新端点(账号+商家身份+一次性初始密码)+ edge 路由 + IT
- 卡 C:用户端登录/注册弹窗去身份选择 + 装载链简化(claim 机制删除、裸账号兜底、切侧回退删除) + vitest
- 卡 D:治理台「用户与积分」页签「初始化商家账号」UI(GlModal)
- 卡 E:e2e 四 spec 登录助手 + 根目录 smoke/verify 脚本 + PRD 身份模型章节更新

**范围外(明确不做,遇到也不处理)**:
- 不做存量数据迁移/清理(D6);不给治理台加「给既有账号开商家」(D5);不做存量裸账号的批量回填迁移(运行时兜底即可)
- 不动治理台登录(OpsApp 本就不传 with-identity-choice,零改动);不动子账号体系(建号/池/挂店/停用等全部照旧)
- 不动 KYB/主体创建/一账号一主体/更名审核/30 天冷却等主体侧规则(仅身份入口姿态随本批自然变化)
- 不改邮箱验证码流程(治理台建号免验证码,管理员背书,同子账号直建先例)
- 不动 identity_session 多设备策略/身份切换审计既有语义;不动积分/账本/结算
- 不做「双身份账号登录时仍显示选择」之类的分支方案(D3 已否)

## 6. 任务卡

### 卡 A:注册即推荐官+自助开通收紧
**背景**:现行注册是裸账号(零身份档案),身份在登录表单上选、由前端编排开通。本批改为注册即推荐官(D1),并把「自助开通商家」的 API 口子关死(D2/D5),为卡 B 的治理台初始化让路。

**改动文件**:
- 修改 `platform-java/services/identity-service/src/main/java/com/grassland/identity/auth/RegisterRequest.java`(删 initialIdentity 组件)
- 修改 `platform-java/services/identity-service/src/main/java/com/grassland/identity/auth/RegisterController.java`(缺省反转+删参数解析)
- 修改 `platform-java/services/identity-service/src/main/java/com/grassland/identity/identityprofile/IdentityProfileController.java`(POST /me/identities 收紧)
- 修改 `platform-java/services/identity-service/src/test/java/com/grassland/identity/auth/RegistrationIdentityIT.java`(整文件重写)
- 修改 `platform-java/services/identity-service/src/test/java/com/grassland/identity/auth/PasswordUpgradeIT.java`(initialIdentity 引用清理)
- 修改 `platform-java/services/identity-service/src/test/java/com/grassland/identity/identityprofile/IdentityProfileControllerIT.java`(商家用例删改+新用例)

**开始前检查**:读 `RegisterController.java` 全文、`IdentityProfileController.java:85-136`、`IdentityProfileRepository.java`、三个 IT 全文;确认 Spring 默认忽略未知 JSON 字段(本地跑一次「请求体多带 initialIdentity」的行为即可确认)。
