## 目标（PRD §4.3 热点与创作灵感）

- 热点筛选补齐：**行业、城市、内容类型**三维度（平台分组已有）
- **有效期**：展示来源/抓取时间之外的有效期，过期趋势默认不出现（PRD「避免使用过期趋势」）
- 保持：匿名可访问、60s/ALAPI 双源、AI 热点拆解链路零改动

**数据现实（设计前提）**：上游 60s/ALAPI 只返回 rank/title/hotValue/url/cover/sourceLabel——**没有任何行业/城市/内容类型元数据**。筛选维度必须平台侧自己打标（见 D1）。

## 实施阶段

### Stage 1 — intelligence：taxonomy + 打标 + 过滤 + 有效期

- `contracts/hot-topic-taxonomy.json`：

```json
{ "version": "hot-taxonomy-v1",
  "industries": { "<对齐 org industry 键>": ["美食","火锅","奶茶","探店","烘焙","…"], "…": ["…"] },
  "cities": ["北京","上海","广州","深圳","杭州","成都","重庆","武汉","西安","南京","苏州","长沙","天津","青岛","厦门","…起步 ~30 城"],
```

- `hottopic/` 新包：`HotTopicTaxonomy`（加载/版本，镜像 PlatformCreationRuleCatalog 的加载方式）、`HotTopicClassifier`（标题打标：industry 多值、city 单值或 null、contentType 单值；无命中=null=「全国/全部」桶）
- 缓存刷新路径接入打标（D3）；`HotItem` 模型加 `tags` + `validUntil`（或包裹层，**不改 60s/ALAPI 上游 record 的解析**，打标发生在缓存组装处）
- `HomepageController` 加查询参数：`industry / city / contentType / includeExpired`（维度内 OR、跨维度 AND；缺省=不过滤，**无参数响应与现状兼容**——仅新增字段）
- 有效期配置（D4）+ 过期默认过滤
- **测试**：打标命中/多标签/无命中；过滤组合逻辑；有效期计算与 includeExpired；无参数向后兼容（既有响应字段全在）；词表版本随响应暴露；匿名访问不回归

## 验收标准

1. 无参数请求 `/api/homepage/hot-items` → 响应与现状兼容（仅新增 tags/validUntil/expired 字段），既有 tab 渲染与 AI 拆解零回归
2. `industry=food`（对齐 org 键）只返回命中美食关键词的热点，跨平台组生效；多行业命中项在任一命中行业下都出现（维度内 OR）
3. `city=上海` 返回提及上海的热点；无城市命中的项在不选城市时可见（「全国」桶）
4. 超过有效期窗口的缓存项默认不返回；`includeExpired=true` 返回且 `expired:true`，前端灰显 + 剩余/已过期标注
5. 词表文件换版本后：新缓存窗口用新词表打标，打标结果随缓存稳定（同窗口不抖动）
6. 匿名访问（未登录）筛选可用，不引入登录门槛
7. 既有 homepage/intelligence 测试零回归

## 代码库陷阱清单（必读）

- Java 构建：JDK 25（`JAVA_HOME=/opt/homebrew/opt/openjdk@25`），入口 `platform-java/` 下 `./gradlew`
- **无新公网前缀**：筛选是既有 `/api/homepage/hot-items` 的查询参数，edge 零改动（确认 RouteManifest 匹配粒度即可）
- **向后兼容是硬约束**：新增字段不得破坏既有前端消费器与 AI 拆解链路（topic-from-hot 只吃 title）
- **intelligence 没有全局 ObjectMapper bean**——持服务本地实例；词表 JSON 解析失败要 fail-fast（启动报错），不静默空词表
- taxonomy 词表经 Java 构建消费（镜像 platform-format-rules 机制），版本号字符串进响应
- 城市词表子串匹配注意「重庆火锅」类合理命中（它确实与重庆相关）；拉丁词用词边界防误伤
- Jackson 3：record 可选数值字段包装类型；`is` 前缀派生态加 `@JsonIgnore`
- Reactor：打标在缓存刷新组装处同步完成（纯内存），无 `switchIfEmpty` 副作用
- 提交按语义拆分（建议：taxonomy+打标+过滤 / 前端 / docs 各一个 commit），中文 commit message、`feat(scope):` / `test(scope):` / `docs:` 风格
