## 目标（PRD §4.11 企业客户：组织配额、成本上限）

- 组织管理员可配置/查看本组织的 AI 预算上限；执行链硬停（`ModelBudgetService.checkAndReserve` → `AiExecutionService`）**已就绪**，本任务补齐「配不出来」的管理入口
- 展示真实用量，让上限可运营

**现状**：`AiModelBudget`（V6，六上限：tokens/cents × per-run/daily/monthly）+ 预留/硬停执行链接入完毕；**无任何 controller/UI 创建或修改预算**；组织级 BYOK 路由仍关闭（`ByokRoutingService.java:16` 注释）；视频生成 cancel 路径透传既有预留（`VideoGenerationService.java:113-116`）。

## 决策表

| # | 决策 | 理由 |

| D1 | 两个端点挂 intelligence 既有 `/api/ai` 树：`GET /api/ai/organizations/{orgId}/budget`（配置+用量快照）、`PUT` 同路径 upsert；**caps 全空/无行 = 不限**（保持现状默认） | 零新公网前缀；无行=不限是既有语义，别改 |

| D3 | 校验：同单位内单调 `per-run ≤ daily ≤ monthly`，违例 400；**允许把上限改到低于当前已用量**（响应带 usage 供 UI 警示「立即生效将挡停后续 run」，不 409） | 运营可能就是想立即止血；警示优于拒绝 |

| D6 | 视频生成 cancel 路径透传=**核对语义并加注释**（取消释放而非消耗，不超预算），不改行为；**组织级 BYOK 开启不在本任务**（独立决策，登记） | 强改反而破坏取消语义 |

## 实施阶段

### Stage 1 — intelligence：预算端点

- `AiOrgBudgetController`：GET（config + usage 快照 + version）/ PUT（upsert + 单调校验 + expectedVersion 乐观锁；全空 caps = 删除行恢复不限）
- org ADMIN/OWNER 判定走 identity 权威内部调用（镜像 content-assets 先例）；非本组织/无权限统一 404
- usage 快照从 ModelBudgetService/V6 记账聚合（D5 边界）
- （若 V6 无 version）小迁移补 `version bigint NOT NULL DEFAULT 1`
- **测试**：IT——权限矩阵（owner/admin 可读写、member 与跨 org 404）、单调校验 400、乐观锁 409、全空恢复不限、**配置后超限 run 真实被硬停**（端到端断言既有 checkAndReserve 生效）、GET usage 只含真实记账字段

### Stage 2 — 前端

- 「AI 预算」卡片：六上限输入（未填=不限）、用量展示（tokens/cents × 今日/本月，数据缺则「暂无计量」）、保存（409 冲突态→重载重试，镜像草稿冲突 UX）
- 挂组织管理区；仅 org ADMIN/OWNER 可见入口（判定用既有前端组织角色状态）
- **门禁**：`npm run test && npm run typecheck && npm run build` + vitest（表单映射/空=不限态/冲突态/用量渲染）

### Stage 3 — 收尾

1. 全量门禁：`./gradlew :services:intelligence-service:test` + 前端三件套
2. 回写进度指南：#37 标完成、第四批第 16 项划掉、登记「org BYOK 开启」「预算告警通知」两个后续
3. CLAUDE.md：`/api/ai` 路由行补 organizations budget 端点一句

## 验收标准

1. org ADMIN 设置月度 cents 上限后，该组织后续平台 run 超限被硬停（IT 端到端断言既有硬停真实生效）
2. member / 其他组织成员访问 budget 端点 404；org ADMIN/OWNER 正常读写
3. `per-run > daily` 等单调违例 400；并发编辑第二写者 409
4. GET 返回六上限（或未设置态）+ 真实用量快照；无计量数据处显示「暂无计量」而非编造
5. 清空全部上限 = 恢复不限，行为与现状一致
6. 既有 `AiExecutionService`/视频生成测试零回归；cancel 路径行为不变（补注释）

## 代码库陷阱清单（必读）

- Java 构建：JDK 25（`JAVA_HOME=/opt/homebrew/opt/openjdk@25`），入口 `platform-java/` 下 `./gradlew`
- **org 鉴权是本任务最大风险面**：intelligence 无组织表，必须走 identity 权威内部调用的既有先例模式；任何「信任请求头/参数里的 org 角色」都是漏洞
- **intelligence 没有全局 ObjectMapper bean**——持服务本地实例
- 金额一律 cents、token 数为整数；上限可空语义（null=不限）贯穿校验与前端
- 新端点确认被既有 `/api/ai` edge 前缀覆盖（粒度核查），否则 fail-closed 404
- Jackson 3：record 可选数值字段必须包装类型（**本任务全是可空数值，全包装**）；`is` 前缀派生态加 `@JsonIgnore`
- Reactor：identity 内部调用是 IO，勿在事务内；`switchIfEmpty` 副作用包 `Mono.defer`
- 提交按语义拆分（建议：预算端点+鉴权接线 / 前端卡片 / docs 各一个 commit），中文 commit message、`feat(scope):` / `test(scope):` / `docs:` 风格
