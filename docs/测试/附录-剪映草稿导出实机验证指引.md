# 附录:剪映草稿导出实机验证指引

> 配套实现:任务书 #66 卡B2(A 轨剪映草稿导出)· 任务书 #69 卡A(验证闭环)。
> 代码锚点:`platform-java/.../videoproduction/export/JianyingDraftBuilder.java`(常量 `SUPPORTED_JIANYING_RANGE`)。
> 机器能验的已由 `VideoJianyingDraftContractTest` 兜底(三轨结构/相对路径布局/微秒时间轴/version 配对/meta 键齐备/降级形态);本指引只覆盖机器不能验的——**在你装了剪映桌面版的电脑上真实打开一次导出的草稿**。

## ① 适用版本区间与下载入口

- 当前锁定区间:**剪映专业版 6.0 – 6.9**(与 `JianyingDraftBuilder.SUPPORTED_JIANYING_RANGE`、导出接口响应头 `X-Supported-Jianying-Range`、前端「导出剪映草稿」按钮旁提示同源)。
- 剪映专业版(桌面版)下载:剪映官网 https://www.capcut.cn/ 的「剪映专业版」(Windows/macOS)。
- 7.x 及以上未验证,不在承诺区间;若 7.x 实测可用,按第⑥节登记后可放宽区间。

## ② 导出步骤

1. 在草场完成一次视频制作并**合成成片成功**(第四步「合成成片」界面)。
2. 在成片结果区点击 **「导出剪映草稿」** 按钮(旁边「导出素材包」是 B 轨通用素材包,不是本指引对象)。
3. 浏览器新开下载:一个 zip,内层结构为 `jianying/caochang-video-<任务id前8位>/` 目录,含 `draft_content.json`、`draft_meta_info.json`、`materials/video/shot-*.mp4`、`materials/audio/shot-*.wav`。
4. 解压 zip,取**整个 `caochang-video-xxxxxxxx` 目录**(不要只取里面的两个 json)。

## ③ 实机打开步骤

把解压出的 `caochang-video-xxxxxxxx` 目录整体放进剪映的**草稿根目录**,然后重启剪映(或在首页草稿列表刷新)即可看到该草稿。

剪映 6.x 默认草稿根目录(以实机为准,不同小版本/自定义安装路径可能不同):

| 系统 | 默认路径 |
|---|---|
| Windows | `C:\Users\<用户名>\AppData\Local\JianyingPro\User Data\Projects\com.lveditor.draft\` |
| macOS | `~/Movies/JianyingPro/User Data/Projects/com.lveditor.draft/` |

在剪映首页「草稿」列表若已可见即放对了位置;若用剪映「打开草稿」对话框手动选择,选中 `caochang-video-xxxxxxxx` 这一级目录。

## ④ 逐项检查清单

打开草稿进入编辑界面后逐项核对:

- [ ] **三轨可编辑**:时间轴上能看到视频轨(逐镜段)、音频轨(旁白 wav)、文本轨(旁白字幕)三类轨道,均可选中、可拖动、可删除;
- [ ] **旁白对齐**:播放任一镜头段,画面与对应旁白音频同步起止,无错位、无静音段;
- [ ] **字幕文本可改**:双击文本轨字幕可进入编辑,改字后正常显示(内容即各镜旁白原文);
- [ ] **素材不丢失**:每个镜头段的素材引用有效(不出现黑屏/离线素材/感叹号占位);草稿里的素材路径为 `/JianYingDrafts/<草稿名>/materials/…` 占位绝对路径,依赖剪映打开时按草稿目录重绑——若报素材丢失,记入第⑤节排查;
- [ ] **微秒时间轴不错位**:轨道总时长 ≈ 成片实际秒数(与成片页「成片 N 秒」一致),镜头之间无重叠、无空洞;
- [ ] **导出/再合成冒烟**(可选加分项):在剪映内直接导出一次视频,产物可播放。

## ⑤ 常见损坏形态排查

| 形态 | 表现 | 处置 |
|---|---|---|
| 素材占位路径未重绑 | 打开后素材离线/黑屏 | 确认整个草稿目录(含 `materials/`)一起拷入;仍失败→按第⑦节登记,注明剪映小版本 |
| 草稿目录混入多余文件 | 剪映报「草稿已损坏」 | 只保留 `draft_content.json`、`draft_meta_info.json`、`materials/` 三项;版本提示等信息我们只放接口响应,不写进草稿目录,若目录里有多余文件请回传截图 |
| version 不符 | 打不开或打开后时间轴异常 | 核对 `draft_content.json` 里 `"version": 360000` 与你的剪映主版本(6.x)是否匹配;不匹配→第⑦节登记 |
| 时长为 0 / 轨道空 | 镜头没进来 | 检查导出任务是否真为「合成成功」态(未完成任务导出会被 409 拒绝) |

## ⑦ 失败反馈路径

验证失败(打不开/损坏/错位/素材丢失)时,在本文件下方登记失败形态,不动代码:

- 登记:失败现象(对照第④/⑤节条目)、剪映完整版本号、操作系统、`draft_content.json` 的 `version` 值、导出任务 id;
- 若多个小版本失败、部分成功:据此收窄 `SUPPORTED_JIANYING_RANGE`(同第⑥节第 2 步);
- 不确定归因时,把 `draft_content.json` 原文(不含 materials 字节)贴进登记行,便于比对字段漂移。
