2. **产品合同**：[草场产品需求文档](产品/草场产品需求文档.md)；旧需求来源只在[归档](归档/全功能营销工具库需求文档（合并前来源）.md)中保留。

4. **当前状态**：[续接指南第四节](草场开发进度与续接指南.md#四当前未完成开发与生产门禁按优先级)和 [`status.yaml`](status.yaml)。续接指南的历史 Slice 段落是实施证据，不是新的待办列表。

## 三个应用入口

| 入口 | 面向对象 | 路由和说明 |
|---|---|---|
| `index.html` | 商家、推荐官、消费者 | `/` 是草场主页；`/grassland` 是登录后的工作台；`/commerce` 是消费者商城；旧 `/ai-center` 深链会外跳 AI 应用 |
| `ai.html` | AI 内容创作 | 独立 AI 创作应用，覆盖文章、图片、视频、朋友圈和脚本工作流；共享草场会话 |
| `ops.html` | 治理、客服、财务和运营 | 独立治理台，包含 `/admin` 管理后台和 `/ops` 运营处置入口 |

## 状态阅读规则

- `已实施`、`VERIFIED` 或交付报告中的 `[x]` 只说明对应文档声明的范围和验证证据，不代表真实供应商、真实资金或生产演练已经完成。
- 真实 PSP/存管/合规、生产凭据轮换、外部 Kafka/Temporal、官方平台指标和供应商账单仍受 D-01 或部署侧门禁约束，具体以续接指南第四节和最近复核报告为准。
- 任务书里写“待浏览器验收”“待外部渠道”“待真实对账”的项必须保留这些限定；不要为了让索引整齐而改成完成。
- 文档中的 `test-artifacts/`、`scripts/local/` 和绝对本机路径是本地证据。它们适合复核当前工作区，不能当作可移植的发布附件。
- `status.yaml` 目前的更新时间是 2026-09-01，仅覆盖 #22–#51。#47、#50、#51 保留其 `in_progress` 声明；#52–#98 按任务书、交付记录和代码核对，不在本次整理中补造状态。
- 任务书 [#100（创作画布闭环与 AI 协作）](任务书/草场任务书-100-创作画布闭环与AI协作.md) 保留原开发规格与执行记录；2026-09-12 复盘发现多项关键闭环缺陷，不能据原完成声明判整体通过。后续修复以 [#102（创作画布复盘修复与真实闭环验收）](任务书/草场任务书-102-创作画布复盘修复与真实闭环验收.md) 的 16 卡/64 组 TC 为准；2026-09-13 C01～16 已 VERIFIED，画布三浏览器27项与完整E2E102项通过，实际媒体、兼容回退及全部门禁证据见任务书附 B；代码尚未提交或部署。

## 可重复检查

```bash
npm run docs:status
npm run docs:links
```

`docs:links` 使用仓库内的[链接检查脚本](../scripts/quality/check-doc-links.mjs)，输出到 `test-artifacts/docs-links/`。它检查 Markdown 文件和图片链接的本地目标、索引可达性与绝对本机链接；缺失文件、不可移植链接或未索引文档会返回非零退出码。应用运行时法律路由与被 Git 忽略的本地证据单独列出，不计作文件错误。检查不访问外网，也不校验页内锚点或报告中的历史代码行号。
