2. `docs/草场开发进度与续接指南.md` 第四节是当前 backlog 和生产门禁的唯一文档真相源。
3. `README.md` 负责使用、运行、路由和安全概览，不单独维护 backlog。
4. `项目速览.md` 只提供会话恢复摘要，必须注明更新时间并链接权威进度指南。
