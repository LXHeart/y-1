## 模型与关键技术真相（动手前必读）

1. **独立/任务生图分叉点**：`ArticleImageController.java:75-102`——`isTaskMode()` 走 `TaskImageGenerationService`（预算闸 + ai_run），否则走 `ArticleImageService.generate`（**legacy 免费路径，无 ai_run**，类注释明说「图片端点保持 legacy 免费语义」）。系列图卡两段式自己接执行环，不沿用免费路径（C 决策）；该不一致由 #56 统一清理，本册不背。
2. **参考图是文本增强不是图生图**：`ArticleImageService.java:83-91`——参考图经 `describe()`（多模态 LLM，免费）转成文字描述与 prompt 拼接后才送 `ImageGenerationClient.generate(prompt, size)`；图像 API 本身不吃图。D 决策在此现实下设计。
3. **管线先例**：`ImageAnalysisService.analyzeIndependent`（:68-103）——`executeIndependentPipeline` 一次计费/留痕/退款闭环，帧序列 prepare/progress/complete/result。卡片计划镜像此姿态；轮次默认两轮（plan → self-check/refine），实现者可按效果调一轮。
4. **批量部分成功先例**：`contentlibrary/PublicAssetBatchGenerationService.java:61-118`——串行 concatMap、每张独立预算闸、逐项 `{ok, assetId?, errorReason?}` 不整体回滚。逐卡生成镜像此语义。
5. **kind CHECK 约束**：`creation_generation.kind` 有 CHECK（V33 建、V43 DO 块重建扩值先例）。V53 按同款 DO 块加 `card_series`，**幂等 DDL 铁律**（TaskLifecycleMigrationTest/OutboxRepositoryIT 重放）。
6. **审核自动触发**：`ArticleImageService.registerGeneratedMedia`（:149-152）登记成功即 `moderateGeneratedAsync` 异步送审、失败静默——复用该注册路径即得审核，无需另接线。
7. **lineage 姿态**：非 SSE JSON 流用强一致 `CreationGenerationRecorder.record`（videorecreation 三处先例）；kind/mode/resolution 枚举语义照 `CreationGeneration.java:29-73`。
8. **前端矩阵唯一映射点**：`resolveWorkflow`（`src/config/ai-platform-capabilities.ts:139-164`）——加带默认值的可选参数，既有调用零变更；模板常量结构先例 `src/constants/video-edit-templates.ts`。
9. **尺寸白名单**：`{1024x1024, 1024x1792, 1792x1024}`（ArticleImageController.java:44）。3:4 精确比例不在集合，V1 用 1024x1792 近似竖版；精确比例属 #56 方言层议题。
10. **生图返回契约**：`ImageGenerationClient` 只认 `data[0].b64_json`（b64 同步返回，无异步 Job）；存储经 `GeneratedImageStore` → `/api/article-generation/generated-images/{id}` URL（30min 缓存头）。

## S1 · 后端（intelligence-service 新包 `cardseries/`）

### S1.1 V53 迁移

`V53__creation_generation_card_series.sql`：V43 同款 DO 块重建 kind CHECK，值域加 `card_series`。若 V53 已被他书占用，顺延取下一空号，**禁止复用已占用号**。

### S1.2 prompt 契约（`CardSeriesPrompts`）

- 计划 prompt：输入 = 平台/主题/来源上下文/卡数/风格布局配色描述词 → 输出严格 JSON `{cards:[{title, bullets[], illustration, caption}]}`（bullets 每卡 ≤5 条；illustration 为配图方向一句话）。
- 每卡生图 prompt：模板描述词 + 该卡计划 + 首卡 revised_prompt 风格锚（第 2 卡起）+ 参考图描述（如有）。
- JSON 解析走既有 stripCodeFence + 严格校验惯例（`ArticleImageService.parseRecommendation` 先例），坏输出 502。

### S1.3 `POST /api/card-series/plan`（SSE）

- 请求：`{platform, source, theme, cardCount(1–9), styleId, layoutId, paletteId?, contextRef?}`。
- `executeIndependentPipeline`（CreditFeature `CARD_SERIES_PLAN`；token 估算参照 ImageAnalysisService 公式量级，输出按计划 JSON 体量给足）→ SSE 帧序列，result 帧带计划 JSON；402/超时走既有 error 帧契约。
- 计划不落库，用户编辑后随 generate 请求回传。

### S1.4 `POST /api/card-series/generate`（JSON）

- 请求：`{platform, cards[编辑后计划], styleId, layoutId, paletteId, size, referenceImages?}`。
- 逐卡：`preparePlatformAsyncExecution("image_generation", null, provider, operationId, unitPriceCents, pricingVersion)`。provider 与价目取 `FrozenImageGenerationConfigResolver.current()` 组装（独立模式无快照，照 `TaskImageGenerationService.java:66-73` 形态；**此处收敛为单点，#56 落地后替换为 resolveProvider 即自动 BYOK 感知**）→ 生图 → `registerGeneratedMedia(CARD_SERIES)`。
- 部分成功语义；响应 `{cards:[{index, url, revisedPrompt, ok, errorReason?}]}`，url 沿用 `/api/article-generation/generated-images/{id}` 前缀。
- 全部卡结束后 `CreationGenerationRecorder.record` kind=`card_series`（mode=independent；result={styleId, layoutId, paletteId, size, cards 摘要}，resultMediaIds=成功卡 media id）。

### S1.5 `POST /api/card-series/cards/{id}/persist`（JSON）

- 校验卡归属 owner → 从 GeneratedImageStore 读字节 → putObject 永久 key `media/card_series/<uuid>` → 新 MediaReference（purpose=`card_series`、source=generated、**无 expiresAt**）→ 返回永久 media id。
- `VideoAssetArchiveService.java:62-86` 归档先例；幂等：同卡重复 persist 返回既有永久行。

### S1.6 后端测试（IT）

计划 SSE 帧序 + 积分扣减 + 402 拒绝；逐卡预算闸（预算不足的卡失败不拖垮整批）；部分成功响应契约；kind lineage 落库断言（mode=independent、resultMediaIds 与成功卡一致）；persist 归属校验（他人卡 403/404）+ 幂等重入；moderateGeneratedAsync 被触发（advisory 断言）。自备容器 IT 涉及新表双处补 DDL。

## 实现红线（历史教训，逐条自查）

- 新流一律 `executeIndependent`/`executeIndependentPipeline` 接入，禁手写扣退/预留。
- `switchIfEmpty` 参数与副作用调用包 `Mono.defer`（Reactor eager-assembly 陷阱）。
- 请求 record 可选数值字段用包装类型；派生态 is 前缀无参方法一律 `@JsonIgnore`。
- 迁移 DO 块幂等；迁移号冲突顺延取空号，禁止复用。
- 自建 WebTestClient 必带 30s responseTimeout（无门禁靠惯例）。
- 生图 bytes 校验沿用 validBase64 惯例；明文密钥绝不入日志/响应/outbox。
