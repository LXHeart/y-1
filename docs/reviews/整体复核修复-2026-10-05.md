## 实现

- `TaskContractTerms` 集中定义需重新同意的条款，纳入审稿要求、期限、取消条款、目标问题和关联套餐；取消条款按 JSON 值比较，忽略键排序。
- Marketplace V67 用同一 SQL 函数生成新报名和新任务版本的合同快照，带 schemaVersion=2。历史快照保持原样；只有重新同意才生成新快照。
- 创建、草稿更新、修订校验交付天数为 null 或正整数；数据库 CHECK 拦新写入，遇到历史非法天数发出迁移警告并保留旧值，不自动重写。接受时也不再把非法期限压成 0。
- 接受与修订通过 task-contract 独立命名空间的事务 advisory lock 串行化。接受在锁内重读任务版本；修订在锁内重评报名状态，避免事务外检查与落库间互相穿透。
- 保留满额任务原有错误语义；同一幂等键并发接受仍回放同一结果，单名额只占用一次、只产生一条命令和事件。
- Intelligence V95 增加观察时间、租约 token、连续失败与最后错误。Worker 每次处理前原子领取一项，按 next_poll_at/id 排序，单并发，每轮上限 50。观察失败退避，进程中断后租约到期可恢复。回写校验 token、attempt、build，拒绝旧观察污染新重试。
- `finished/failed` 变体进入 failed，可重试；complete 仍须归档结果就绪才成功。
- 通知首页去重包含筛选；分页绑定查询代次并去重；已读成功时废弃旧列表与计数请求，保留跨账号 epoch 防护。
- README 改用资源守卫和明确模块构建，列出由基础 Compose 静态展开核实的依赖集合。
