# 三端前端样式检查与修复

日期：2026-09-15。代码基线：`206418d8bac5`，结果对应本次工作区改动。

本次按根 `DESIGN.md` 与 `src/ops/DESIGN.md` 检查用户端、AI 创作端、治理台及共享组件，修复字号、主题对比度、移动端布局和键盘交互问题。静态扫描覆盖 `src/` 下 213 个 Vue/CSS 文件；截图覆盖 81 个页面或功能状态，分别检查亮色、暗色与桌面、手机布局。

## 修复内容

| 范围 | 发现的问题与修复 |
|---|---|
| 全局设计变量 | 补齐、校正语义字号和颜色映射，组件改用 `--type-*`；治理台保持 22px 页面标题、18px 区块标题；亮暗主题同步调整。修复未定义变量导致的 AI/登录品牌图标变黑，以及选中背景、状态提示文字对比度不足。 |
| 字体与控件 | 替换过小、随父级缩小的文字；统一按钮、字段、说明字号。桌面主要控件至少 40px，移动端至少 44px；移动端文字输入使用 16px。修正复选框、单选框被通用控件样式拉伸，以及返回首页等链接按钮文字未垂直居中的问题。 |
| 响应式布局 | 修复视频制作表单、图片生成与喜剧工具栏、推荐官长任务标题和顶部账号区溢出；宽表格在自身容器内滚动。修复治理台账号详情将整组内容挤进 64px 列的问题。 |
| 页面层级 | 登录后的首页直接展示工作入口，身份信息放入工作区标题；文章完成预览、法律文档正文与标题使用相应语义字号，长文本自然换行。 |
| 弹窗与键盘 | 共用弹窗焦点和滚动管理，处理背景不可交互、嵌套弹窗、Escape 关闭和关闭后焦点恢复；为 20 处页签组接入方向键、Home/End 切换；补齐输入标签、图标按钮名称、跳到主要内容链接与可见焦点。争议卡片改用语义导航链接。 |
| 视觉一致性 | 移除组件内硬编码颜色、`transition: all`、悬浮抬升、发光与模糊效果；调整涉及组件的间距、圆角和状态表面。图片编辑导出使用的内容颜色移至独立常量模块，保留导出语义。 |

## 已知非样式问题

- WebKit 的 `M1 用户端任务草稿可由地址直接恢复并再次刷新` 偶发在立即刷新时记录 `due to access control checks`，使第 60 行“无运行时错误”断言失败；草稿标题实际恢复成功。在未修改基线 `206418d8bac5` 的相同夹具环境中，重复运行也出现 1 通过、1 失败。证据为 `creation-studio-webkit-baseline-warm.log` 和 `webkit-refresh-diagnostic.log`。没有通过删除断言掩盖失败。
- 争议页在首次直接访问、身份尚未加载时会回到首页。本次通过登录后的工作台进入争议列表及详情检查样式，认证时序问题未在本次修改。
