- 仓库内文档和源码使用相对链接；`#L123` 等代码行号保留报告当时的定位，后续代码移动时按类名、方法名和报告基线复核。
- `test-artifacts/` 和 `scripts/local/` 是被 Git 忽略的本地证据；相对链接方便当前工作区查看，但新克隆不会自动带上这些文件。
