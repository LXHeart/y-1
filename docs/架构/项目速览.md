# 草场项目速览

> 这是一份给新会话和维护者使用的入口笔记，不是产品合同。产品规则以 [`产品/草场产品需求文档.md`](../产品/草场产品需求文档.md) 为准，架构取舍以 [`adr/README.md`](../adr/README.md) 和 HLD 为准，当前 backlog 以 [`../草场开发进度与续接指南.md`](../草场开发进度与续接指南.md) 第四节为准，机器可读状态以 [`docs/status.yaml`](../status.yaml) 为准。

## 项目定位

草场（Grassland）是商家、推荐官和消费者共用的种草推广任务撮合平台，包含 AI 内容创作中心和到店消费闭环。

- 任务撮合主链：发任务 → 报名 → 预留 → 履约 → 核验 → 确认 → 争议 → 结算 → 钱包。
- 到店消费主链：推广 → 套餐 → 支付 → 核销 → 分账/退款 → 评价。
- 两条链路目前都是 Sandbox 语义；真实 PSP、存管、合规主体和外部对账完成前，不得上线真实资金。

## 三个入口

| 入口 | 作用 | 代码位置 |
|---|---|---|
| 用户端 | 草场主页、任务工作台和消费者商城 | `index.html`、`src/router/`、`src/views/` |
| AI 创作端 | 独立创作应用，共享草场会话 | `ai.html`、`src/ai/`、复用 `src/views/` |
| 治理台 | 管理、客服、财务、风控和运营处置 | `ops.html`、`src/ops/` |

用户端 `/` 是草场主页，`/grassland` 是工作台，`/commerce` 是消费者商城；旧 `/ai-center` 深链会跳转到独立 AI 应用。治理台的 `/admin` 和 `/ops` 不属于用户端路由。

## 技术拓扑

```text
浏览器 → Nginx → edge-bff:8080（唯一公网 API 入口）
                         ├─ identity-service:8082
                         ├─ marketplace-service:8083
                         ├─ finance-service:8084
                         ├─ trust-service:8085
                         └─ intelligence-service:8086

PostgreSQL · Redis · Kafka · Temporal · MinIO/S3 · Prometheus/Alertmanager/Grafana
```

前端是 Vue 3 + Vite + TypeScript + Pinia；后端是 Java 25 + Spring Boot 4.1 + WebFlux/R2DBC + Gradle Kotlin DSL。Node 只用于前端构建、测试、E2E seed 和工具链；Intelligence 容器内的 Node 只作为 Java Playwright driver，不承载 HTTP 或领域逻辑。

## 服务边界

| 服务 | 责任 |
|---|---|
| `edge-bff` | RouteManifest、会话和移动 token、服务断言、CSRF、SSE/Multipart/Range 透传；未登记、方法不匹配或关闭的路由 fail-closed 404 |
| `identity-service` | 账号、会话、组织、门店、成员、身份、准入、KYB、通知和后台角色 |
| `marketplace-service` | 任务、报名、履约、核验、确认、退出、消费订单、声誉、归因和经营分析 |
| `finance-service` | 双录账本、托管、支付/退款/分账 Sandbox、钱包、积分和对账 |
| `trust-service` | 争议、举证、审判官、投票、上诉、客服终审和判例 |
| `intelligence-service` | AI 运行、平台模型/BYOK、媒体、素材、草稿、创作上下文、视频和内容安全 |

共享能力位于 `platform-*` 模块，包括存储、加密、身份断言、HTTP、消息、数据库和财务政策。服务间读取通过内部断言、WebClient 或事件投影完成，不能跨服务直读业务表或共用 ORM Entity。

## 关键不变量

1. **资金不可变**：Finalized 账本只能追加 Reversal；余额由 posting 重建，未知的外部结果不能被当成明确失败。
2. **积分幂等**：消费、退款和实际用量调整都有稳定 operation id；上游失败才退款，用户主动中止不退款。
3. **创作快照不可变**：任务版本、平台规则、素材和 AI 配置在进入任务创作时冻结，生成链路绑定同一 snapshot id。
4. **服务端授权为准**：前端显隐不是权限；组织、门店、审判官和治理角色均由对应 Java 服务校验。
5. **路由 fail-closed**：停用的 `EDGE_ROUTE_*` 只返回 404，不回切 Express 或其他隐式上游。
