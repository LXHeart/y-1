## 项目定位

草场（Grassland）是商家、推荐官和消费者共用的种草推广任务撮合平台，包含 AI 内容创作和到店消费能力。

- 任务撮合：发任务 → 报名 → 预留 → 履约 → 核验 → 确认 → 争议处理（如有）→ 结算 → 钱包。
- 到店消费：推广 → 套餐 → 支付 → 核销 → 分账/退款 → 评价。
- 资金链路按 Sandbox 语义运行；真实 PSP、存管、合规主体和外部对账仍受 [ADR D-01](../adr/D01-psp-escrow-compliance.md) 门禁约束。

## 三个应用入口

| 入口 | 面向场景 | 主要路径 |
|---|---|---|
| `index.html` 用户端 | 商家、推荐官、消费者 | `/` 主页、`/grassland` 工作台、`/commerce` 商城、`/creation` 任务创作 |
| `ai.html` AI 创作端 | 自由创作与项目工作区 | 独立 origin 的 `/` 与图文、图片、视频工作流 |
| `ops.html` 治理台 | 管理、客服、财务、风控与运营 | 独立 origin 的 `/admin`、`/ops` |

旧 `/ai-center` 深链跳转独立 AI 应用。跨应用通过一次性免登协议衔接账号，各 origin 使用自己的 Cookie；详见[架构详解](项目架构详解.md#12-前端与创作工作区)。前端为 Vue 3 + TypeScript，后端为 Java 25；技术拓扑和数据边界只在架构详解维护。
