## 目标

四条工作流，各自独立交付：

1. **创作矩阵补全**：`reference`（参考素材）来源放开到全部合法「平台 × 内容形式」——参考分析仍只支持
   抖音/B 站链接提取，但**输出**不再限定这两个平台（分析小红书可、图文亦可）
2. **公共素材 AI 批量生产**：内容审核员批量 AI 生成公共库素材（图标/装饰/背景/氛围图），自动落
   pending 进既有审核队列；顺带补齐**从未有前端消费的公共素材审核台 UI**
3. **重复度 / 低原创度 / 行业 overlay 检测**：内容指纹 + 同任务跨账号与自我历史查重（advisory）、
   词库行业/平台 overlay（依托 #24 已冻结进创作上下文的门店品类）
4. **词库在线运营**：L1 词库从静态文件迁为 DB 版本化 + admin CRUD + 运行时激活（文件降为种子）

**本期不做**（防扩散，勿顺手实现）：

- 履约提交硬门槛（内容安全 blocking）——维持 ADR-D16「advisory 不自动阻断」决策，独立立项
- 原创度 ML 评分模型——原创度提醒=确定性指纹查重+文内重复率，不伪造「原创分」
- 多模态输入安全检查（图片/视频内容审核）——仅文本
- 词库灰度/定时生效/回滚审批流——版本激活即生效，历史版本可查
- 参考提取新平台（除抖音/B 站外的链接解析）——PRD 明确只支持两家
- 批量生产的视频/文案类公共素材——仅四类图片
- 跨服务语料（marketplace 履约提交物、legacy 站内内容）入查重语料——只查 intelligence 内生成流指纹

## 验收标准（整体）

1. 词库在线化：admin 建新版本（含一条新词）→ 激活 → 60s 内生成流 L1 命中新词；旧版本 retired 只读；快照冻结的 label 与激活时点一致；非 admin 403；edge 未开 flag 404
2. overlay：任务模式（门店品类含「美食」）生成含 food overlay 词的内容 → finding 带 `appliedOverlays:["food"]`；无对应 alias 的品类静默不叠加
3. 重复度：同任务两账号先后生成高相似文本 → 第二次产出 `duplicate_content` finding（含相似度、无对方文本）；90 天窗口外不命中；指纹写失败注入不阻断生成
4. 批量生产：content_reviewer 批量 3 张（其中 1 张注入上游失败）→ 响应 2 ok 1 fail、2 条 pending 素材入审核队列、media 无过期时间；admin 台 approve 后公共库列表可见、语义检索可命中
5. 审核台：pending 队列渲染 + approve/reject 生效（后端既有端点首次有 UI 消费）
6. 矩阵：reference × 小红书视频 / reference × 知乎图文 / reference × 点评图文 均可进分析器且「带入创作」落到正确目标视图；moments×reference 仍 planned；`npm run test` 矩阵快照测试全绿
7. 全量门禁：intelligence + edge-bff gradle test 绿；`npm run test && npm run typecheck && npm run build` 全绿；五条生成流既有测试零回归

- 词库/指纹响应白名单手写 map；他人内容与词表一律不下发
- edge fail-closed：新前缀 `/api/admin/content-safety` 不注册即 404；内部端点不进 `/internal/**`
