# 全功能营销工具库 — 需求文档

> 本地优先的短视频提取、内容创作与营销工具平台

## 1. 项目概述

### 1.1 产品定位

面向内容创作者和营销人员的全功能工具平台，提供视频提取分析、图片评价文案生成、爆款文章创作、脱口秀脚本生成、AI 图片生成、视频内容改编等功能。

### 1.2 技术栈

| 层级 | 技术选型 |
|------|----------|
| 前端 | Vue 3.5 + Vite + TypeScript |
| 后端 | Express 5 + TypeScript |
| 数据库 | PostgreSQL |
| 页面抓取 | Playwright（Chromium） |
| HTML 解析 | Cheerio |
| 音频处理 | ffmpeg |
| 输入校验 | Zod |
| 日志 | Pino |
| 测试 | Vitest + Supertest |

### 1.3 用户角色

| 角色 | 说明 |
|------|------|
| 未登录用户 | 可使用视频提取、预览、下载等基础功能 |
| 普通用户 | 注册登录后可使用 AI 分析、文章生成、图片生成等积分消耗功能，并拥有独立设置 |
| 管理员 | 拥有普通用户所有权限，额外可管理用户和调整积分 |

## 2. 功能模块

### 2.1 首页（热点聚合）

**需求描述：** 展示多平台实时热点，作为产品入口引导用户使用各功能。

**功能要点：**

- 展示抖音、微博、知乎等多平台热点内容
- 支持两种数据源切换：
  - **60s API**（默认）：聚合抖音/微博/知乎热点，缓存 2 小时
  - **ALAPI**：需配置 Token，展示抖音/微博/微信/小红书热点，缓存 5 分钟
- 热点数据缓存在数据库中
- 首页提供功能入口，可跳转到各功能模块
- 可预填文章主题或脱口秀主题

**页面元素：**

- Tab 栏切换不同平台热点
- 功能快捷入口卡片
- 热点列表（标题 + 热度）

---

### 2.2 视频提取分析

**需求描述：** 解析抖音和 Bilibili 短视频，提供预览、下载、音频提取和 AI 内容分析。

#### 2.2.1 视频提取

**功能要点：**

- 用户粘贴分享文本或链接，后端解析出视频地址
- 支持抖音和 Bilibili 两个平台
- 视频预览/下载走后端签名代理，不暴露上游地址给前端
- 代理 URL 必须是本站相对路径或与 `PUBLIC_BACKEND_ORIGIN` 同源
- 抖音支持音频提取（ffmpeg 后端处理）

**抖音特殊机制：**

- 常规提取：直接解析分享链接
- 登录增强（fallback）：通过 Playwright 启动浏览器，用户扫码登录后提取
- 登录增强仅作为 fallback，不是默认提取路径
- Session 管理支持轮询、登出

**Bilibili 特殊机制：**

- 支持 BV 号和分享链接解析
- 支持分 P 视频提取

#### 2.2.2 视频分析

**功能要点：**

- 对提取的视频进行 AI 内容分析（需登录、消耗积分）
- 视频时长超过 10 分钟不支持分析（耗时过长、可读性差）
- 最佳体验时长：30 秒到 2 分钟

**分析提供者架构：**

- 支持两种提供者：**Coze 工作流** 和 **Qwen（OpenAI 兼容接口）**
- 提供者和凭据由服务端持久化设置决定，浏览器不能直接调用第三方服务
- 配置优先级：服务端用户设置 > 环境变量默认值
- 视频分析服务按设置分发到对应提供者

---

### 2.3 图片评价文案

**需求描述：** 上传商品图片，AI 生成对应平台的评价文案，支持一键复制和导出飞书文档。

**功能要点：**

- 支持上传最多 6 张图片（multipart）
- 选择目标平台：淘宝 / 大众点评
- AI 生成评价文案（SSE 流式输出）
- 一键复制生成的文案
- 导出飞书文档（需登录）
- 支持评价风格记忆（保存/读取用户偏好）
- 风格偏好优化（AI 辅助优化评价风格）

**多步骤生成流程：**

1. 草稿生成（step/draft）：上传图片 + 平台信息 → 生成初稿
2. 文案优化（step/optimize）：对初稿进行优化
3. 风格精修（step/style-refine）：按用户风格偏好精修

---

### 2.4 爆款文章创作

**需求描述：** 从主题到成稿的全流程 AI 文章创作，支持多平台适配和按段落配图。

**创作流程：**

1. **输入主题** → 选择目标平台（微信公众号 / 知乎 / 小红书）
2. **生成标题** → AI 生成多个候选标题，用户选择
3. **生成大纲** → SSE 流式输出大纲，用户可编辑调整
4. **生成正文** → SSE 流式输出正文
5. **按段落配图** → 为每个段落推荐/搜索/生成配图，用户可跳过单个段落

**配图方式：**

- AI 推荐图片
- 图片搜索
- AI 生成图片（支持参考图上传，最多 4 张）

**技术约束：**

- 文章生成仅支持 Qwen 提供者
- SSE 使用 `fetch` + `response.body.getReader()`，非 EventSource

---

### 2.5 脱口秀创作

**需求描述：** 仿李继刚风格生成脱口秀脚本，SSE 流式输出。

**功能要点：**

- 输入主题，AI 实时生成脱口秀脚本
- SSE 流式输出，实时展示生成过程
- 需登录、消耗积分

**技术约束：**

- 生成时使用 `enable_thinking: false` 防止推理内容混入输出

---

### 2.6 图片生成

**需求描述：** 独立的 AI 图片生成功能，支持文本描述和参考图上传。

**功能要点：**

- 输入文字描述生成图片
- 支持上传参考图
- 支持 @mention 功能
- 需登录、消耗积分

---

### 2.7 视频内容改编

**需求描述：** 将视频分析结果转化为分镜脚本，并支持生成对应的场景图片。

**功能要点：**

- 基于视频分析结果进行内容改编
- 支持用户自定义改编指令
- 支持上传参考图片（最多 4 张）
- 生成改编脚本（角色、场景、道具等）
- 根据脚本生成场景图片（单张 / 批量）
- 需登录、消耗积分

**API 端点：**

- 内容改编（adapt-content）：上传参考图 + 自定义指令 → 生成脚本
- 资产图生成（generate-asset-image / generate-all-asset-images）：生成角色/道具图片
- 场景图生成（generate-scene-image / generate-all-scene-images）：生成场景图片
- 批量生成带限流保护

---

### 2.8 账号系统

**需求描述：** 邮箱注册登录系统，按用户隔离设置和积分。

#### 2.8.1 注册流程

1. 获取图形验证码（`GET /api/auth/captcha`）
2. 发送邮箱验证码（`POST /api/auth/send-code`，需正确图形验证码）
3. 提交注册（`POST /api/auth/register`，需邮箱验证码）

#### 2.8.2 登录

- 邮箱 + 密码登录
- 失败登录限流：per-IP + per-account-IP 滑动窗口

#### 2.8.3 Session 管理

- PostgreSQL 持久化 session（connect-pg-simple）
- 支持 `/api/auth/me` 获取当前用户信息
- 支持 `/api/auth/logout` 登出

**安全措施：**

- 密码使用 scrypt（bcryptjs）哈希存储
- Session Cookie 签名
- 登录失败限流

---

### 2.9 积分系统

**需求描述：** 功能使用扣积分，防止滥用，管理员可调整。

**功能要点：**

- 新注册用户自动获得 3 积分（可通过 `FREE_CREDITS_ON_REGISTER` 调整）
- 以下操作扣除 1 积分：视频分析、图片评价、文章生成、脱口秀生成、图片生成、视频改编
- 积分扣减使用原子操作 `UPDATE ... WHERE balance >= 1 RETURNING`（防止并发超扣）
- 所有积分变动均有记录（credit_transactions 表）
- 积分历史查询

**管理员功能：**

- 查看所有用户列表
- 调整任意用户的积分（增加/减少）

---

### 2.10 管理后台

**需求描述：** 管理员专用页面，管理用户和积分。

**功能要点：**

- 仅 admin 角色可见（标签页条件渲染）
- 需要 `requireAuthenticatedUser` + `requireAdmin` 双重中间件
- 查看用户列表（分页）
- 调整用户积分

---

### 2.11 设置系统

**需求描述：** 按用户隔离的个性化配置，包括 AI 分析设置和首页热点设置。

#### 2.11.1 分析设置

- 选择分析提供者（Coze / Qwen）
- 配置 API 地址、API Key、模型名
- 模型验证（verify-model）：测试配置是否可用
- 密钥留空 = 保留已保存的密钥；输入空格后保存 = 清空密钥
- 需登录

#### 2.11.2 首页设置

- 选择热点数据源（60s API / ALAPI）
- 配置 ALAPI Token
- 需登录

---

### 2.12 主题切换

**需求描述：** 支持亮色/暗色/跟随系统三种主题模式。

- Header 提供主题切换按钮
- 三种模式循环切换：light → dark → system → light
- 使用 CSS 变量实现主题

## 3. 非功能需求

### 3.1 安全

| 安全措施 | 说明 |
|----------|------|
| 视频代理 | 走后端签名 URL，不暴露上游地址 |
| Trusted host | 只允许受信任的视频 host 进入代理链路 |
| SSRF 防护 | `provider-url.ts` 维护白名单，匹配时跳过私有 IP 检查 |
| 注册安全 | 图形验证码 + 邮箱验证码双重验证 |
| 密码安全 | scrypt 哈希存储 |
| 积分安全 | 原子操作扣减，防止并发超扣 |
| 管理员安全 | 双重中间件认证 |
| API 限流 | 所有端点带基础限流，登录失败有独立限流 |
| 凭据隔离 | 分析凭据由服务端管理，前端不能直接调用第三方 |

### 3.2 性能

| 指标 | 说明 |
|------|------|
| SSE 流式输出 | 文章和脱口秀生成使用流式输出，减少用户等待感知 |
| 热点缓存 | 60s API 缓存 2 小时，ALAPI 缓存 5 分钟 |
| Body 限制 | JSON body 最大 1MB |
| 超时控制 | 各 API 调用均有超时设置（视频分析最大 600s） |
| 音频处理 | ffmpeg 后端异步处理，含超时保护 |

### 3.3 可用性

- 不配置数据库时应用仍可正常运行，但无账号系统、积分和热点缓存
- 环境变量定义在 `server/src/lib/env.ts`，是运行时配置的唯一来源
- 支持 Docker Compose 部署（前后端拆分容器，Nginx 反向代理）

### 3.4 可观测性

- Pino 结构化日志（请求日志 + 应用日志）
- 可配置日志级别
- `/health` 健康检查端点

## 8. 部署方案

### 8.1 本地开发

```bash
npm install
npx playwright install
cp .env.example .env      # 编辑环境变量
npx tsx server/src/scripts/run-migrations.ts  # 初始化数据库
npm run dev                # 前后端同时启动
```

### 8.2 生产构建

```bash
npm run build              # 前后端一起构建
npm run start              # 生产模式启动（后端托管前端 dist/）
```

### 8.3 Docker Compose

- 前后端拆分容器
- 前端通过 Nginx 反向代理 `/api` 到后端
- 默认映射：前端 8080→80，后端 3000→3000
- 不包含 Playwright 浏览器登录增强

```bash
cp .env.docker.example .env.docker   # 编辑配置
docker compose --env-file .env.docker build
docker compose --env-file .env.docker up -d
```
