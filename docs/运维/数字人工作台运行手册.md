## 2. 环境搭建（A修订通过后适用）

当前pyproject/uv.lock仍含旧上游重推理依赖，先按A01/K14移除并重新冻结再执行以下命令；不要用旧196包基线作为新版安装清单。固定上游源码本身可保留，运行时仅导入受控编排/媒体部分。

```bash
# 1) 固定上游 + 冻结依赖（只允许 github/codeload 下载源码归档；禁止权重下载）
python3 platform-realtime/digital-human/scripts/bootstrap.py --fetch
python3 platform-realtime/digital-human/scripts/bootstrap.py --resolve-lock
uv sync --project platform-realtime/digital-human --python 3.11 --frozen

# 2) 复验（零写入；vendor 被改动会逐文件点名）
uv run --project platform-realtime/digital-human --frozen \
  python platform-realtime/digital-human/scripts/bootstrap.py --verify-only

# 3) 测试基线（30 用例：bootstrap 15 + fake 4 + import 4 + probe 7）
uv run --project platform-realtime/digital-human --frozen python -m pytest \
  platform-realtime/digital-human/tests -q
```

## 3. 运行合同（S0 边界）

- **只跑受控面**：`grassland_dh.app.create_app(test_mode, surface)`——internal 控制面（health +
  INTERNAL01～04 最小实现）与 audio 面（仅精确 WS 路径，未到 C/D 认证合同一律 4401）。
  绝不启动上游 `apps.api.main`；原生 /sessions、runtime-config、memory、outputs 路由不存在（有测试锚定）。
- **生产默认关闭**：`DH_ENABLED=false` 时写路径一律 503 `dh_runtime_unavailable`，不派发任何 provider。
- **Fake 全链零外网**：STT/LLM/TTS/Renderer 全 Fake（`grassland_dh.fakes`）；测试以 socket 级
  OutboundGuard 实证外网请求=0。禁止用 Edge TTS 冒充 Fake（K10/K13.2）。
- **内容红线**：上游补丁删除 `SpeechTiming.text_preview` 与 6 处正文日志；原始 mic 不落盘、不进素材库；
  会话正文仅内存易失缓冲（K05）。
- **全部第三方模型**：LLM/STT/TTS/render及模型形象预处理均使用现有控制面配置；不下载权重、不部署本地模型。旧`quicktalk-local`候选与权重许可清单必须在A04移除，改为第三方配置引用、服务条款、协议能力及资产证据，unknown不可approved。
