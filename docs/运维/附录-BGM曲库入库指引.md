# BGM 曲库入库指引（运营附录）

> 配套：草场任务书 #64《视频制作管线重构》卡7 / 卡11。治理台「BGM 曲库」页签的上传与许可规范。

## 曲库定位

- 成片合成的配乐池：合成时按分镜的情绪建议（bgm-advice 的 `moodDirection.label`）自动选曲，
  匹配不到时随机取任意启用曲；曲库为空则合成跳过 BGM（不报错）。
- 平台运营资产：`bgm_track` 直连对象存储（`bgm/{uuid}`），不占用户素材配额、不随用户删除。
- 每镜候选、重抽、TTS、BGM 均不单独计费（P2 一口价已包含）。

## 入库标准（硬性）

| 项 | 要求 |
|---|---|
| 许可 | **CC0 / 公有领域**优先；免版税商业授权（royalty-free，含再分发与衍生合成权利）可接受；要求署名（BY）或禁商用（NC）的一律不入 |
| 格式 | mp3 / m4a（服务端按文件魔数校验，改后缀无效） |
| 大小 | 单文件 ≤ 10MB（建议 1–3 分钟剪辑版，循环拼接由合成器处理） |
| 命名 | 「情绪-曲名-版本」如 `轻快-清晨市场-主旋律`；治理台曲名 1–100 字 |
| 情绪标签 | 至少一个，受控八值：轻快 / 温暖 / 治愈 / 燃 / 悬念 / 舒缓 / 国风 / 电子 |

## 推荐来源

| 来源 | 许可 | 说明 |
|---|---|---|
| [Pixabay Music](https://pixabay.com/music/) | Pixabay License（免版税、可商用、无署名要求） | 首选；下载页保留许可截图 |
| [Free Music Archive（CC0 筛选）](https://freemusicarchive.org/) | 按曲目标注 | 只收 CC0 / CC-BY 可商用档；BY 曲需在「曲名」尾注作者 |
| [Incompetech](https://incompetech.com/music/royalty-free/) | 免版税（需署名） | BY 类：曲名尾注 `by Kevin MacLeod` |
| Musopen（古典） | CC0 / PD | 公有领域古典曲，适合国风/舒缓 |

入库前逐曲核对来源页的许可徽标；任何来源存疑的曲子宁缺毋滥。

## 操作步骤（治理台）

1. 平台管理员登录治理台 → 「BGM 曲库」页签（admin-only）。
2. 「上传曲目」：选择音频文件、填写曲名、勾选情绪标签（可多选）→ 上传。
   - 上传后系统自动 sniff 格式、测时长（ffprobe），时长展示为空不影响使用。
3. 「试听」校听整曲；命名/标签有误用列表操作修正（当前版本编辑走启停，改名可联系开发批量处理）。
4. 曲目默认启用；临时下架用「停用」（保留行），确认不再使用才「删除」。
   - **被成片任务引用过的曲目删除会自动降级为停用**（引用行保留曲目标识，历史可追溯）。

## 情绪映射（选曲时如何被命中）

| bgm-advice 情绪 | 命中的曲库标签 |
|---|---|
| 轻快 | 轻快、电子 |
| 温暖 | 温暖、治愈 |
| 燃 | 燃 |
| 悬念 | 悬念 |
| 舒缓 | 舒缓、治愈 |
| 其它 | 任意启用曲 |

复合情绪词按包含式匹配（「温暖治愈的夜晚」→ 温暖/治愈）。建议每个情绪至少入库 2–3 首，
避免同情绪单曲被高频重复选中。

## 混音参数（固定，不可配）

- 有配音：旁白音量 1.0，BGM 0.2（衬底）。
- 无配音：BGM 0.9。
- BGM 短于成片时自动循环（`-stream_loop -1`），长时截断。

## 验收清单（每次入库后过一遍）

- [ ] 试听完整曲无破音、无突然截断。
- [ ] 情绪标签与听感一致（误标会导致选曲错配）。
- [ ] 来源许可截图/链接归档到运营共享盘。
- [ ] 曲名不含艺术家署名以外的推广文案。
