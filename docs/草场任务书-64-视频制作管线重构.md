## 1. 目标与背景

**一句话目标**:视频制作从「纯文本脚本 + 单镜头模型直出」重构为「结构化分镜 → 逐镜图生视频(多 take)→ TTS 配音 → 字幕/BGM → FFmpeg 合成」的全链成片管线;模型凭据与计价收敛进治理台;无视频凭据时降级「图文成片」;计费改为按成片实际秒数一口价。

**用户拍板记录(2026-09-01,执行期不得更改)**:

| # | 拍板点 | 结论 |
|---|---|---|
| P1 | TTS | MiniMax TTS,凭据/模型在治理台「AI 模型」功能配置 |
| P2 | 计费 | **一口价:按成片实际秒数 × 单秒价**;预估按目标时长、结算多退少补;多 take/重试/TTS/BGM 不单独计费 |
| P3 | BGM 曲库 | CC0/免版税曲库,治理台上传管理 + 情绪分类(种子为空,附运营入库指引,见卡7) |
| P4 | 字幕 | 硬字幕烧录 + SRT 文件下载,二合一 |
| P5 | 多 take 抽卡 | **一期做**:每镜默认 2 个候选(治理台可配 1–3),挑选 UI + 单镜重抽 |
| P6 | 兜底图文成片 | **一期做**:无视频凭据自动降级,前端不锁死 |
| P7 | 万相 3.0 | **一期加**,凭据/模型在治理台配置 |
| P8 | 分镜流式格式 | SSE 逐镜流 JSON(NDJSON 逐行解析转发,见 4.1) |
| P9 | 成片时长 | 15–60 秒用户自定义(步进 5) |
| P10 | 分辨率 | 一期固定 9:16 1080p(合成统一 scale 到 1080×1920) |

## 4. 定死文本(执行期逐字落地)

### 4.1 分镜 SSE 契约(替代 generate-script)

```
POST /api/video-production/storyboard        (登录;沿用 ScriptRequest 字段与校验 + 新增 targetDurationSeconds 15..60 步进5)
resp SSE 帧(逐帧 JSON):
  {"type":"meta","targetDurationSeconds":N}
  {"type":"shot","shot":{"seq":1,"visual":"画面描述","narration":"旁白","plannedSeconds":5,"cameraMove":"缓慢推近","anchorImageIndex":2,"prompt":"生成提示词"}}
  ... (逐镜随 LLM NDJSON 行到达即转发)
  {"type":"safety", ...(沿用现有安全帧结构)}
  {"type":"error","message":"..."} 或数据流自然结束([DONE])
```
- system prompt 要求 LLM **逐行输出 NDJSON**(每行一个 shot 对象,字段同上,anchorImageIndex 为 1 基,无图镜头 0),后端逐行解析转发;**不要求 LLM 输出 meta 行**(meta 来自请求)。
- 分镜硬约束写进 system prompt:单镜 4–6 秒、镜头数 3–10、画面主体 ≤5、总 plannedSeconds 尽量贴近 targetDurationSeconds、首镜按 2 秒钩子设计、每镜 prompt ≤100 字。
- 落库:storyboard(任务上下文快照同现脚本步)+ shots 行;旁白全拼 + prompt 全拼过 `checkShallow`,结果走 safety 帧。
- 旧 `POST /api/video-production/generate-script` 保留兼容一个版本(内部转发产出首镜 narration 拼文本),前端不再调用;若 e2e 或契约矩阵引用了旧路径,同卡更新锚。

### 4.2 StoryboardPrompts system prompt 骨架

```
你是短视频分镜导演。根据店铺信息、图片与要求,输出营销短视频的结构化分镜。
输出格式:逐行输出 JSON(NDJSON),每行一个镜头对象,字段:
{"seq":整数,"visual":"画面描述","narration":"该镜头旁白","plannedSeconds":4到6的整数,
 "cameraMove":"运镜","anchorImageIndex":1基图片序号或0,"prompt":"给视频模型的生成提示词,≤100字"}
硬性约束:
1. 每镜 prompt 必须主动描述画面人物正在执行的动作(如:端起菜品、看向镜头)。
2. 每镜 prompt 必须重复关键道具与人物状态(前镜出现的产品、服装、动作要延续,不得凭空消失或出现)。
3. 连续镜头之间动作与道具保持连续性;不改变叙事结构;保留镜头节奏。
4. 服装、发型等人物特征在每镜 prompt 持续描述,避免前后外观漂移。
5. 不过度约束:留出空间让模型自由发挥,避免堆砌限制导致穿帮。
6. 首镜(narration 与画面)按「开头 2 秒让人停住」设计钩子。
7. 画面主体(人物+产品)总数 ≤5。
8. cameraMove 从以下选:固定机位/缓慢推近/缓慢拉远/左右横移/跟随运镜/环绕/俯拍下摇/仰拍上摇/特写切换/手持感轻晃/升降镜头/旋转。

10. 总 plannedSeconds 尽量贴近 {targetDurationSeconds} 秒(±10%)。
只输出 NDJSON 行,不输出任何解释或代码围栏。
```

### 4.5 一口价计费

- 建任务:`prepareMediaExecution(capability=video_generation, CreditFeature.VIDEO_PRODUCTION_VIDEO, estimated = targetDurationSeconds × 单秒价)`;operationId 幂等沿用。
- 合成完成:`settleSuccessWithCost(actualCents = round(成片实际秒数) × 单秒价)`——实际秒数取合成产物 ffprobe 时长四舍五入;预估与实际差自动多退少补(执行环既有语义)。
- 整链失败/取消:`handleFailure/handleCancellation` 释放预留(全额退)。
- 重抽、多 take、图文成片、BGM:**不追加用户费用**(预估内消化)。
- TTS 每镜调用走 `prepareExecution(capability=video_tts, feature=null)` 免费分支(平台资助,ai_run 留痕、预算/并发闸生效,照 ContentSafetyAiChecker 模板)。
- 分镜生成计费不变(video_production_script 既有);治理台单秒价变更后新任务按新价,进行中任务按冻结价。

### 4.6 前端形态与文案

- 四步 steps:**上传素材 → 编辑分镜 → 生成与挑选 → 合成成片**;stage 值 `upload|storyboard|generate|compose`(结果在 compose 步内展示)。
- 第 1 步新增字段:成片时长(滑杆 15–60,步进 5,默认 30)。
- 第 2 步逐镜卡片(参考 CardSeriesPanel 形态):每镜「第 N 镜」徽标 + 画面描述 textarea + 旁白 textarea + 运镜下拉(4.2 词表)+ 锚定图缩略(点开换图)/「无锚定图」+ 时长(4–6 数字)+ 删除;底部「添加镜头」(≤10)与「重新生成分镜」。

### 4.7 合成规则(FFmpeg)

- 统一规格:1080×1920、fps 30、h264 + aac;每 take 先 normalize(scale+pad、trim/pad 到该镜音频时长)。
- 音画对齐:音频时长 > 视频时长且差 >8% → 音频 `atempo`(上限 1.3)再对齐;其余情形视频 `tpad` clone 末帧补齐后按音频时长截断;无音频(无配音模式)→ 取 plannedSeconds。
- 拼接:concat demuxer(统一编码参数后);默认硬切。
- 字幕:`subtitles` 滤镜 + `force_style`(FontName=Inter,FontSize=13,白色主体+黑色描边,MarginV=60;Inter ttf 打包进 `resources/fonts`,`fontsdir` 指定)——ASS 样式常量单独定义,不进 CSS token 体系;滤镜路径转义(冒号/引号)按 ffmpeg 规则处理。
- BGM:有配音 → BGM 音量 0.2 与旁白 amix(旁白 1.0);无配音 → BGM 0.9;无曲库/未选曲 → 跳过 BGM。BGM 尾部不足循环 `-stream_loop -1` + 截断。
- 图文成片:每镜 `zoompan`(奇数镜推近/偶数镜拉远,Ken Burns)生成该镜视频,之后走同一合成链。
- SRT:由各镜音频起止时间累计 + cues 生成,随任务落对象存储(presign 下载)。
- 执行:走 MediaProcessRunner 新增的超时可传重载(合成上限 600s);临时文件 MediaArtifactStore + finally 清理。
- sandbox IT 产物:`SandboxVideoGenerationProvider` 升级为 ffmpeg lavfi(testsrc,color)生成 540×960 2s 真实 mp4;新增 `SandboxTtsProvider` 生成正弦波 wav(时长=旁白字数/4 秒,最少 1s)——确定性、可合成、可断言。
