# 草场使用说明

> 面向商家、推荐官、消费者、AI 创作者与平台运营人员。
>
> 校准日期：2026-09-15。产品规则见 [PRD](草场产品需求文档.md)，文档分工见[产品文档索引](README.md)。安装与启动从[根 README](../../README.md#快速开始)开始。

## 一、入口与使用范围

草场围绕推广任务、AI 内容创作和到店消费组织业务，三个应用共用草场账号：

| 入口 | 用途 | 主要路径 |
|---|---|---|
| 用户端 | 商家与推荐官工作台、消费者商城、任务内创作 | 工作台 `/grassland`、商城 `/commerce`、任务创作 `/creation` |
| AI 创作端 | 自由创作、门店创作、项目与素材、模型和预算管理 | 独立 AI 应用首页，以及对应图文、视频工作流 |
| 治理台 | 审核、账号管理、财务、风控与运营处置 | 管理后台 `/admin`、运营处置 `/ops` |

使用部署方提供的三个应用地址；本地默认地址见[根 README 的入口表](../../README.md#三个应用入口)。用户端与 AI 应用支持免登跳转，登录过期时按页面提示重新登录。

**当前使用范围**：仓库提供 Web 应用，资金链路使用 Sandbox；真实支付、存管、外部对账和原生 APP/小程序不因页面存在而视为已开放。AI 真实渠道取决于模型配置和验收状态；新增图文工作台与公众号同步默认关闭，见[第五节](#五ai-内容创作)。

## 二、账号、登录与个人设置

### 获得账号

| 使用者 | 账号来源 | 首次使用 |
|---|---|---|
| 推荐官、个人创作者、消费者 | 在统一入口使用邮箱注册 | 填写昵称、密码，完成图形和邮箱验证码，阅读协议与隐私说明；注册默认获得推荐官身份 |
| 商家负责人 | 平台在治理台初始化商家账号，仅接受全新邮箱 | 使用平台交付的一次性初始密码登录，先修改密码，再创建商家主体 |
| 商家成员 | 主体负责人或管理员在成员管理中直接建号 | 使用完整账号名和一次性初始密码登录，先修改密码；按分配的组织和门店权限操作 |
| 平台工作人员 | 为既有账号授予相应后台角色 | 从治理台登录，使用获授权的功能 |

登录支持“账号名或邮箱 + 密码”。成员账号名形如 `主体前缀-登录名`；绑定邮箱后也可用邮箱登录。忘记成员账号初始密码时联系主体管理员重置。

注册与登录表单均不选择商家/推荐官身份。新账号按来源获得身份，不能自助补开商家身份，也不能把已注册账号邀请为商家成员。存量双身份账号继续受已有身份和资源权限约束；身份规则详见 [PRD 第一章](草场产品需求文档.md#一平台概述)。

### 个人设置

用户端工作台的“个人设置”集中提供：

- **主页与分享**：推荐官资料、社交账号与分享信息。
- **账号与合规**：邮箱绑定、登录会话与个人数据操作。
- **举报与投诉**：提交投诉和查看处理记录。
- **判例库**：查看已脱敏的争议案例。

主题按钮在亮色、暗色与跟随系统之间切换。个人 AI 密钥和预算在 AI 应用的“AI 与治理”中管理。

## 三、商家工作台

### 入驻与日常入口

首次改密后创建商家主体，完善品牌、门店、联系方式、素材和认证资料。创建主体时自动建立默认门店；商家准入分为草稿、基础发布、资金交易三级，当前开放能力以“权限与额度”的审核结果为准。

| 页签 | 主要操作 |
|---|---|
| 任务与报名 | 创建任务、查看审核和报名、处理履约与凭证 |
| 商家主体与门店 | 概览、成员与门店、品牌资料、认证资料、权限与额度 |
| 资金与经营 | 资金账户、月度账单、到店套餐与核销、经营分析 |

单店时界面收敛为“我的门店”，不提供成员建号入口；开设第二家门店后进入多店管理。多店成员由主体负责人/管理员创建与分配，一个成员最多挂一家门店，一店最多一名店长。停用可恢复，删除成员账号为永久作废，操作前核对完整账号名。

### 发布推广任务

1. 选择门店、发布平台与内容形式，填写任务要求和授权素材。
2. 选择一种合作模式：**霸王餐/实物兑换、任务量佣金、套餐推广**。三种模式不可组合。
3. 按模式填写报酬或关联已上架套餐，设置报名截止、交付期限、是否发布前审稿以及取消条款。
4. 查看任务预览、条款和金额说明，提交审核；通过后按流程开放报名。
5. 在“任务与报名”处理申请。报名被接受并完成资金保障后，双方按冻结的合同版本履约。

套餐推广先在“资金与经营 → 到店套餐与核销”创建并上架套餐，再由任务关联。套餐价格和分成在套餐管理中设置，任务表单不重复设置。同一套餐同时只能关联一个进行中的推广任务。

**修改边界**：已有报名被接受或进入资金预留时，任务不可再编辑；仅有待处理报名时，修改按版本和重新确认规则生效。停止报名不终止已接受的合作。

**付费互动已停止新增**：不再创建或修订为点赞、收藏、关注、评论类互动任务。历史互动任务保留原履约流程直至自然结束。

### 审稿、验收与异常处理

- 合同要求发布前审稿时，先处理推荐官提交的草稿；草稿通过后仍需发布并提交正式凭证。
- 依据任务要求检查发布链接、附件、指标及核验结果，确认、要求补交或说明异议。页面会显示当前责任方、截止时间和可执行动作。
- 核验结果存疑或证据缺失时按提示进入复核，不能把等待超时当成无条件付款。
- 涉及取消、失约、延期或协商退出时，按合作内的对应动作处理；已有里程碑的补偿以合同和服务端金额预览为准。
- 接受报名、结算、退款等操作可能先显示处理中，以后续实际结果和资金流水为准。

完整履约规则见 [PRD §2.3](草场产品需求文档.md#23-任务管理)，资金时序见 [PRD 第八章](草场产品需求文档.md#八资金托管与结算)。

### 从门店创作

使用工作台的“从门店创作”进入 AI 应用，核对自动带入的门店资料与素材。该入口锁定组织和门店，按组织上下文执行。

组织预算、组织模型密钥和主体创作审计已统一迁到 **AI 应用 → AI 与治理 → 商家主体治理**，仅向有管理权限的账号开放。用户端商家工作台不再单设“AI 与治理”页签。

## 四、推荐官工作台

| 页签 | 主要操作 |
|---|---|
| 任务大厅 | 按条件筛选任务，查看门店、要求、报酬、条款和报名资格 |
| 我的任务 | 查看报名与合作进度、下一步动作、期限、创作入口与交付记录 |
| 收益与结算 | 查看余额、收入和结算状态 |

### 内容或体验任务

1. 完善个人资料与目标平台账号，再查看任务要求、费用、期限和授权范围。自填的粉丝数等信息不等于平台已认证数据。
2. 报名并等待商家处理；需要重新确认条款时先核对变更。看到合作已接受后再开始履约。
3. 体验任务按约预约、到店或收样，并确认商家权益兑现；失约时使用合作内的举证入口。
4. 需要 AI 协助时，从该任务的创作入口进入用户端 `/creation`，核对锁定的任务、门店、平台和素材。
5. 按合同完成草稿审阅、发布和正式凭证提交。**生成内容、保存草稿或审稿通过，都不等于完成发布交付。**
6. 根据核验、补交、商家验收和观察期提示继续操作，最终在收益页核对结算流水。

无责退出、延期和协商退出只在符合规则时开放；协商申请被拒绝、撤回或超时后，原合作继续，原交付期限不会自动暂停。

### 套餐推广任务

接任务后，通过任务内的分享入口生成并复制推广链接或二维码，不手工拼接推荐官账号。有效归因按 **7 天窗口内末次触达**确定；自购、无资格或失效链接不计推荐官佣金。

消费者购买后仍需到店核销。核销后进入 **48 小时冷静期**；未决售后或已确认暂扣会阻止分账。收益页的待结算和已结算需要分别查看，部分退款后以实际净额为准。归因问题走申诉，不能自行改写订单归属。

争议通过合作内入口或“我的争议”处理；小法庭、客服直裁与上诉的区别见 [PRD 第七章](草场产品需求文档.md#七争议处理机制)。

## 五、AI 内容创作

### 先选对入口

| 创作场景 | 从哪里进入 | 上下文与费用归属 |
|---|---|---|
| 个人自由创作 | AI 应用 → 开始创作 | 自选主题、热点或参考素材；按个人模型来源、额度和预算执行 |
| 商家门店创作 | 商家工作台 → 从门店创作 | 锁定门店与组织，按组织配置和预算执行 |
| 推荐官任务创作 | 已接受任务 → 创作入口 | 留在用户端 `/creation`；使用冻结的任务上下文、授权素材和 AI 策略 |

在“开始创作”选择发布平台，再选择该平台支持的内容形式与来源。任务或门店深链带入的锁定信息不可改成其他任务、组织或门店。

### 常用工作流

| 工作流 | 操作顺序与结果 |
|---|---|
| 图片评价/探店文案 | 上传图片、填写真实体验、选择目标平台 → 生成草稿 → 优化与精修 → 人工确认、复制或导出；飞书导出需先配置授权 |
| 长图文与文章 | 输入主题 → 标题、大纲、正文 → 按段落配置图片 → 检查、编辑和交付 |
| 朋友圈 | 选择图片配文或视频配文，导入素材与主题，生成并调整文案 |
| 图片生成与编辑 | 输入描述、选择授权参考图或素材 → 生成或编辑 → 检查结果并保存 |
| 风格化脚本 | 输入主题与表达要求 → 流式生成 → 编辑与保存 |
| 视频参考分析与改编 | 粘贴有权使用的抖音/Bilibili 分享链接或导入参考素材 → 解析分析 → 带入脚本、角色、场景和分镜 |
| 视频成片 | 导入素材和门店/主题 → 分镜规划与编辑 → 生成、比较候选 → 配音、字幕、BGM 与合成 → 审核后下载 |
| 分镜画布 | 打开视频画布，编排镜头与素材、预览并确认 AI 修改方案、挑选候选，再进行合成与交付 |

上传数量、大小、时长与费用以页面和当前模型能力提示为准。视频制作当前时长控件为 15–180 秒，计费按成片实际秒数结算；生成前查看预估，完成后核对实际费用。失败补偿与主动取消按对应运行规则处理，不把点击取消视为退款完成。

**新增图文工作台与公众号同步**：[#101](../任务书/草场任务书-101-AI创作工作流与图文交付升级.md) 已有本地实现和复核记录，但默认关闭；真实模型、真实公众号和完整部署栈仍需验收。部署方开放后，可使用原稿导入、修改建议、视觉计划、图卡/封面、排版交付和公众号草稿同步。同步到公众号草稿不等于公开发布。启用与回退步骤见[根 README](../../README.md#图文工作台与公众号同步)。

### 项目、素材与运行记录

- **最近项目**：查看已保存项目并继续编辑，核对保存状态和版本。
- **素材库**：使用个人、门店或公共授权素材；以实际可见范围为准。
- **运行记录**：查询生成进度、失败原因、用量与费用；异步任务以实际状态为准。

草场任务创作面只保留任务创作与素材库，其他个人能力在独立 AI 应用中使用。

### 模型、密钥与预算

在 **AI 与治理** 中选择个人模型来源：

- **平台模型**：按平台价目、免费额度和个人预算执行。
- **自有模型密钥（BYOK）**：登记所需能力的密钥，由服务端加密保存和调用；缺少对应密钥的能力不可用，不会悄悄改用平台付费模型。切换前阅读页面对免费能力与计费的说明。
- **商家主体治理**：负责人/管理员管理组织预算、组织密钥与主体创作审计；个人模型来源开关不改变组织执行链。

密钥操作按当前面板的保存、验证和管理入口执行。旧“分析设置”中空白/空格表示保留或清除密钥的做法已退役。

平台模型由运营在 **治理台 → 内容与 AI → AI 模型** 配置；报“未配置”时先确认模型来源、能力和配置。不能通过设置旧模型环境变量修复。AI 积分、AI 预算、现金余额与推荐官等级是不同概念，扣费与退回以运行记录和资金流水为准。

## 六、消费者购买、核销与售后

1. 从商城或推荐官推广链接进入套餐，核对门店、内容、价格、有效期和可预约时段。
2. 登录后下单，在订单显示的支付期限内完成支付；超时订单按流程关闭。
3. 在订单中查看核销码，按约到店，由有权限的商家人员核销。
4. 在“我的订单”查看支付、核销、退款及售后结果。遇到服务问题，及时在售后窗口内发起申请。

结算前按订单状态和售后规则处理全额或部分退款，累计退款不得超过实付。**订单佣金已结算后，买家退款、售后裁定退款和管理端退款均被拒绝**；分账处理中也不能假定仍可退款。具体边界见 [PRD §8.3](草场产品需求文档.md#83-到店核销模式资金流)。

消费者能力属于统一账号，不需要另开身份；购买时不必切换商家/推荐官视角。当前仓库中的支付与分账为 Sandbox 流程。

## 七、平台运营与治理台

管理后台按以下五组组织，具体页签和动作由账号角色决定：

| 分组 | 常见操作 |
|---|---|
| 审核队列 | KYB、主体更名、推荐官认证、任务、权限、审判官准入、媒体与素材审核 |
| 用户与主体 | 用户管理、账号前缀、等级与权益 |
| 交易与财务 | 财务对账、积分套餐、订单核销、经营看板与分析 |
| 内容与 AI | AI 模型、创作风格、BGM 曲库、首页热点、视频任务 |
| 风控与审计 | 风险调查、统一审计 |

运营处置入口处理处置单、待判定事项、投诉与争议等队列。客服可从争议队列读取脱敏详情，或从相关处置单进入；页面可见不等于拥有全部处置权限。

平台管理员可以初始化商家账号、按权限停用或恢复账号、重置密码和授予后台角色。停用商家负责人时，关联组织也会冻结；恢复账号与恢复组织分别处理。审核、调账和角色变更应填写原因，并保留系统审计。

首个平台管理员的部署引导见[根 README](../../README.md#管理员与后台角色)；音乐入库、许可审核和下架见 [BGM 曲库指引](../运维/附录-BGM曲库入库指引.md)。

## 八、常见问题

| 现象 | 处理方式 |
|---|---|
| 注册收不到邮箱验证码 | 核对邮箱和垃圾邮件，按页面倒计时重试；持续失败由运维检查邮件服务 |
| 登录后必须改密，AI 功能不可用 | 先返回用户端完成首次改密，再继续创作 |
| 找不到商家开通或成员邀请入口 | 商家账号由平台初始化，成员由主体直接建号；已有个人账号不能在此加开或被邀请入主体 |
| 商家不能发布或操作资金 | 到“商家主体与门店 → 权限与额度”检查认证、审核和额度；提交申请不等于已获权限 |
| AI 报未配置、预算超限或额度不足 | 到“AI 与治理”核对个人/组织上下文、模型来源、对应能力密钥、预算和余额 |
| 看不到组织 AI 管理 | 进入 AI 应用“AI 与治理”；该区域仅向主体负责人/管理员展示 |
| 视频解析或生成失败 | 检查参考来源、页面限制与运行错误；提供任务/运行编号给运营核查，不反复创建相同收费任务 |
| 图文工作台或公众号功能不可用 | 先确认部署方是否已开放 #101 的功能开关与渠道能力 |
| 任务有成果但仍未结算 | 查看正式凭证、核验、验收、观察期、争议和资金操作状态；AI 生成或草稿通过不等于交付完成 |
| 核销后佣金仍未到账 | 查看 48 小时冷静期、退款、未决售后、暂扣及实际分账结果 |
| 订单提示已结算、不支持退款 | 按该订单规则处理，正常售后须在窗口内提出；不要通过重复提交或管理端绕过 |
| 治理台看不到某个页签 | 核对账号后台角色；菜单与服务端均按角色控制 |
