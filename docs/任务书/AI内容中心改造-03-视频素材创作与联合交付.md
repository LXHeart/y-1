## 1. 完成后用户能做什么

用户不必提供店铺照片，可以从自有视频、录屏、已有脚本或配音进入制作。不同平台得到适合的策划结构，视频、字幕、封面和发布配文一起预览、恢复和导出；修改配文不会重新制作视频。超出当前成片能力的 B站专题可以先交付完整脚本与资料。

## 2. 工作范围与顺序

| 子项 | 实施内容 | 独立验收结果 |
| --- | --- | --- |
| 3.1 输入分支 | 区分店铺照片、自有媒体、已有脚本；同步修改前后端校验与提示词 | 无店铺信息也能用合法脚本/自有媒体开始，旧店铺照片流程继续可用 |
| 3.2 素材计划与现有制作管线 | 每镜记录已有/待生成素材、原始引用、裁剪范围；复用候选片段、配音、字幕、合成 | 自有媒体直接参与制作；缺素材可定位；已有配音/字幕不被无故重做 |
| 3.3 平台策划与专题脚本 | 在任务 1 的平台信息传递上补题材结构；B站脚本关联章节与来源 | 形成可拍摄、可继续剪辑的脚本与素材计划，长专题不会创建必然失败的渲染任务 |
| 3.4 视频发布材料 | 独立编辑封面、描述、话题、字幕和选定分享配文；视频号与朋友圈视频联合交付 | 改配文不触发视频生成；改旁白只标记相关字幕/成片待复核 |
| 3.5 九平台交付集成 | 接入任务 2 的联合预览/readiness，复用既有视频素材包与剪映导出；验收跨入口恢复、来源回跳与九平台清单 | 三份任务的近期目标形成完整闭环，生成完成与公开发布保持分离 |

默认按 3.1 → 3.2 → 3.3 → 3.4 → 3.5 执行。任务 1 已修复的平台字段遗漏不在本任务重复重构。

## 3. 各平台视频最低适配

| 平台 | 策划与交付要求 |
| --- | --- |
| 抖音 | 开场、脚本、镜头/素材、口播和字幕；发布描述/话题与旁白分别编辑 |
| 快手 | 人物、过程、演示及真实结果，保留用户所选口吻；提供拍摄脚本与素材缺口 |
| 视频号 | 受众问题、可信案例与归纳；平台描述、群分享和朋友圈配文分别编辑，按选择生成 |
| B站 | 论点、证据、演示、章节脚本及来源；按能力交付短片或专题脚本/素材包；真实成片后计算时间轴 |
| 朋友圈视频 | 自有视频与共用短配文联合预览、恢复和导出，无需默认店铺资料 |
| 小红书/大众点评的已开放视频入口 | 沿用任务 1 的真实资料、身份和平台规则，并交付平台所需的封面、描述、媒体和声明 |

九平台覆盖通过任务 2 的图文能力与本任务的视频能力组合完成；不为未开放的“平台 × 形式”组合强行增加入口。

## 4. 关键契约与异常行为

- `inputMode` 在 DTO、前端、服务校验与解析中同源。店铺照片分支保留旧必填；自有媒体校验归属、媒体类型、时长和画幅；脚本分支以脚本和交付目标为入口，不要求虚构店铺名。
- 当前 `StoryboardRequest` 复用店铺/图片校验的行为必须与新分支一起调整，不能只在页面隐藏必填项。任务来源仍需合法快照与授权素材，新增素材遵守既有授权流程。
- 镜头记录原素材稳定引用及裁剪范围；分镜、候选和制作任务留在既有服务端表中。工作区保存 `storyboardId/productionTaskId` 等引用，不把所有镜头媒体重复塞进 20 个已选交付引用。
- 当前生成管线约束为 15-180 秒、单镜 4-6 秒、最多 30 镜，开工时重新核对。超出能力时支持 `script-only` 或实际可提供的素材包，不冒称已产出长视频或不存在的剪辑工程。
- 自有视频直接进入素材计划和剪辑，不能全部转成照片再付费生视频。具体处理能力以现有管线和可验证的增量实现为准。
- 发布描述、朋友圈配文、镜头旁白和字幕独立存储。改配文不使视频重生成；改旁白保留旧版本，提示关联字幕/成片待更新，未受影响镜头继续复用。
- 字幕时间与章节时间轴取实际制作结果；只有脚本时不生成看似准确的时间戳。音视频不支持或资源失效时显示具体缺项，文字/结构仍能恢复。
- 视频成品复用 `GET /api/video-production/tasks/{id}/export/bundle` 与 `/export/jianying`。只有脚本、尚无制作任务时，通过任务 2 的草稿导出能力扩展脚本/来源/已授权素材导出，不伪造 productionTaskId。
- 联合导出关联确定的草稿交付版本与制作结果版本；素材包正文、配文、字幕和封面不混用新旧版本。下载过期重新取授权链接，导出失败不触发生成。
- AI 使用、商业合作、原创分别检查；裁切/转码后核验适用标识保留。发布页只显示可证实的生成、保存和交付状态，不把文件生成成功标成平台发布成功。
- 跨平台改编创建新草稿并记录来源草稿/版本；任务草稿不得沿用不匹配的新平台快照。相关路径沿用任务 1 的来源契约，任务 3 负责端到端回归。
