## 3. 技术决策

| 编号 | 决策 |
|---|---|
| D97-01 | 「已结算」判定以**订单佣金分账/结算事件已落账**为准（结算事实存在），不以钱包余额、订单状态推断；三条路径（买家退款、售后争议裁定退款、管理端资金动作）收敛到同一守卫函数；拒绝返回 409 + `blockedReason=settled_no_refund`，沿用现有错误信封。 |
| D97-02 | 时序保证：结算条件必须含「无开放售后争议」；若现状缺此条件则补齐——使「结算后无退款」在时序上成立，闸门为防御纵深而非唯一防线。正常售后须在售后窗口内提出（窗口语义不变）。 |
| D97-03 | 付费互动停供=封创建与修订（contentForm=interaction → 400，reason 说明停供），存量数据零迁移；存量任务的展示、报名、提交、审稿、结算路径全部保持现状至自然到期/终结。 |
| D97-04 | 协商退出：exit_request 事实表；商家/推荐官任一方可发起，对方在 72h（可配 `marketplace.engagement.exit-response-hours`）内确认或拒绝，超时=申请失效、合作按原履约继续；发起方可撤回 pending 申请；同一合作同时最多一个开放申请（partial unique）。 |
| D97-05 | 确认后按 C96-02 已确认里程碑 + 合同取消条款部分结算（无里程碑=零补偿全额释放，同开工前取消），终态 `exit_kind=negotiated`、名额回收；协商退出不暂停任何既有计时（原交付期限、审稿窗口照常），任一终态（超时终结/商家取消/无责退出）先到则申请自动 cancelled。 |
| D97-06 | 协商退出终态声誉口径同无责退出：不进完成率分母、不进失败分母；已发生的部分结算按既有口径计入统计。 |
| D97-07 | 开放争议（disputed）中的合作不可发起协商退出（先走争议）；已有开放协商申请时不可发起争议（互斥，条件 UPDATE 单边胜出）。 |

## 4. 目标行为

### 4.1 退款闸门

买家发起退款 / 治理台裁定售后退款 / 管理端资金动作 → 统一守卫：订单结算事实存在 → 409 `settled_no_refund`，前端文案「订单佣金已结算，不支持退款；售后申请须在售后窗口内提出」；结算事实不存在 → 走既有退款逻辑不变。

### 4.2 协商退出

发起（reason 必填）→ 对方待办出现「待退出确认」（72h 倒计时）→ 确认：按里程碑部分结算、终态、名额释放；拒绝/超时/撤回：申请关闭，合作继续。终态先到则申请作废。

### 4.3 不变量

- 同一经济事实幂等键唯一（退款幂等键沿用现状）。
- 同一报名最多一种终结路径胜出（协商确认 vs 商家取消 vs 超时终结条件 UPDATE 单边胜出）。
- 协商结算金额 ≤ 已预留金额，且必须引用里程碑行（同 D96-04 审计要求）。
- 存量互动任务行为逐字节不变（停供只封入口）。

## 5. 业务规则与权限

## 6. 接口契约

既有 {success,data,error} 信封与身份断言不变。变更与新增（新端点登记 Edge RouteManifest）：

- `POST /api/v2/orders/{id}/refund`：行为变更——已结算返回 409 `settled_no_refund`（非新端点）。
- 售后争议裁定/管理端资金动作：同一守卫（非新端点）。
- `POST /api/tasks/{id}/applications/{appId}/exit`：kind=negotiated 从 409 占位改为创建申请，返回 `{exitRequestId, status:'pending', respondDeadlineAt}`。
- `POST /api/tasks/{id}/applications/{appId}/exit-requests/{exitId}/confirm|reject`：仅对方账号。
- `POST /api/tasks/{id}/applications/{appId}/exit-requests/{exitId}/cancel`：仅发起方，pending 可撤。
- `GET /api/tasks/{id}/applications/{appId}/exit-requests`：双方查自己的申请列表（含预演结算金额）。
- 动作契约扩展（非新端点）：`nextActionGroup` 新增 `exit_pending_confirm` / `exit_await_response`，`blockedReason` 支持 `exit_request_open`（互斥入口）。

状态码：400 参数；401 未登录；403 越权；404 不存在；409 状态/互斥/已结算闸门；503 下游不可用。
