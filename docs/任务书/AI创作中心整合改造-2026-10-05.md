## 1. 产品决策

主导航统一为创作首页、我的项目、素材库、创作助手、工具箱、设置与用量。首页按文案与图文、图片、视频组织；个人创作与草场任务/门店上下文的权限边界不变。

实时对话数字人退出产品方向。新的数字人口播面向平台预设主播照稿出镜，穿插商品图片/视频，默认竖屏、支持横屏。它属于视频制作方式，复用项目、素材、配音、字幕及交付能力。

## 2. 本次落地

- 新建统一工作区装配组件，旧创作中心作为内部功能面复用；草场内嵌入口保持原行为。

- 图片生成与图片编辑并入图片工作区；语音聊天与草稿/内容检查并入助手工作区。
- 我的项目内提供创作项目、参考视频项目及生成记录；参考视频项目使用原 Hypit 查询，保留真实工程 ID 与编辑器，不迁移底层表。
- 工具箱收纳转写、图片处理及字幕/封面等视频辅助工具；设置复用模型、预算、账号连接和受权限控制的组织管理。
- 路由支持前进/后退；旧任务/门店上下文、原制作页、Hypit 工程深链继续兼容。
- `/digital-human` 跳转视频入口并说明退役，不传递旧 session/profile 参数；`/voice-chat` 跳转统一助手。
- 删除 39 个旧实时数字人视图/组件/composable/测试文件，以及旧 API 客户端、客户端测试与类型文件。清理旧导航测试中的实时客户端用例，替换为新导航与退役测试。

- 从普通视频风格选项中移除“数字人口播”。历史类型/后端值仍保留兼容，避免把普通生成模型当作口型服务。
