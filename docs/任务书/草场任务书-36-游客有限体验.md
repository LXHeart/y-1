## 目标（PRD §4.11 游客行 / §4.1）

- 未登录游客可**有限体验**选定 AI 能力（现状只有「可浏览」，生成动作前后端一致硬 401）
- 试用带动注册转化：额度用尽 → 登录引导 + 新用户赠送文案
- 防刷边界明确：匿名身份 + IP 双层限额，试用面不含高成本能力

**现状**：`HomepageController` 热点对未登录开放（`resolveOptional` 先例）；生成端点各 preflight filter 缺断言一律 401（`VideoScriptPreflightFilter.java:63` 等）；前端按钮禁用 + 弹登录（`CreationAssistantPanel.vue:77-78,101-102,128-137,191-196`）。

## 额度策略决策包（Phase A 誊写为 ADR）

### R1 体验目录：3 项白名单，配置驱动

| capability | 形态 | 选它的理由 |
|---|---|---|
| `article-titles` | 输入主题 → SSE 流式 5 个候选标题 | 最便宜的单发展示 |
| `content-score` | 粘贴文案 → 5 维评分 + 优化建议 | 镜像创作助手 score，价值密度高 |
| `image-review` | 上传 1 张图（base64）→ 一段探店点评草稿 | 旗舰多模态能力展示 |

- **明确排除**：视频制作（异步 job 高成本）、抖音/B 站提取（带宽型工具）、视频改编、图片生成、草稿/设置/BYOK/任务上下文。目录做成配置列表（`ai.guest-trial.capabilities`），扩容不改代码面
- **既有生成端点鉴权零改动**（fail-closed 不动）

### R2 额度：匿名身份主键 + IP 双层兜底

- 每 capability **3 次/天**（配 `ai.guest-trial.daily-limit-per-capability`，按 capability 可覆写）
- IP 日上限 **30 次/天**（所有 capability 合计；Redis INCR + 当日 TTL，镜像 identity 断言 replay 防护的 `SET NX + TTL` 用法）——cookie 被清掉也刷不穿的真正闸门
- IP 短窗限流 **10 次/分钟**（挡脚本重试）
- 默认值进 ADR；生产可经配置收紧或经总开关 `ai.guest-trial.enabled=false` 整体关闭

### R3 匿名身份：httpOnly 随机 cookie

- 首次访问经 trial 端点发放：`gtid`（随机 UUID，httpOnly、长 TTL、SameSite=Lax；属性沿 `SessionCookiePolicy` 同款 env 约定）
- 额度键 = `gtid`；cookie 被用户清除 → 额度重置，由 R2 IP 层兜底（ADR 明记此权衡）

### R4 计量与账本：intelligence 轻量表，**不进 finance 积分**

- `guest_trial_quota(gtid, capability, day, used, PK 前三者)`，扣减用原子 `UPDATE ... WHERE used < :limit RETURNING`（镜像 finance credits 的原子扣减范式）
- 审计：`guest_trial_run(gtid, capability, ip_hash, outcome, created_at)` append-only；**不存原始 IP/UA**（SHA-256 截断哈希），无任何个人数据
- **商业化边界（ADR 核心）**：游客试用 = 平台赞助的营销动作，**不建虚拟账号、不写 credits 流水、不产生对账噪音**；注册后才有用量账户与新用户赠送（既有 `CreditsService` 注册赠送路径）。试用产物（草稿/评分）**不持久化、不迁移**——无账号可迁，PRD「不保存敏感设置」的自然延伸

### R5 独立窄面：`/api/guest-trial/{capability}`（POST，SSE）

- 单一 controller + 白名单路由：cap 不在目录 → 404；请求体各 cap 专属（image-review 用 base64 内嵌，≤4MB，不落对象存储）
- SSE 判别帧复用既有约定（progress/result/error；boolean/number 原生下发）；失败 → `{error}` 帧，**额度不扣**
- 成功才计次（R6）；调用走 `TextCompletionClient`/多模态通道（镜像 ai_visual 的执行边界，boundedElastic）

### R6 计次语义

- **成功才算一次**（provider 失败/超时不烧游客额度）；重试刷由 R2 短窗限流兜住
- 扣减时机：provider 成功返回后、SSE 收尾前；扣减失败（并发超限）不影响已产出内容，仅下次拒绝

### R7 注册转化钩子

- 前端额度徽标（「今日剩余 N 次」）+ 用尽后登录引导弹层，文案带新用户赠送额度（读配置值，不硬编码）
- **不加**注册时迁移/补偿试用记录的逻辑（R4 边界）

### R8 隐私与合规

- 只存：随机 gtid、能力名、IP 哈希、结果、时间；不存输入内容与生成产物（内存态即焚）——ADR 记录该取舍（可追溯性对游客降级为「发生过什么」，PRD §4.14 的运行留痕义务以账号为前提）

## Phase B 实施阶段

### Stage B1 — intelligence：trial 面 + 额度 + 审计

- `GuestTrialController`（`/api/guest-trial/{capability}`，POST→SSE）+ `GuestTrialCatalog`（白名单+每能力校验/请求 record）
- `GuestTrialQuotaRepository`（原子扣减 + 当日初始化）+ `GuestTrialRunRepository`（append-only 日志）
- `GuestTrialRateLimiter`（Redis：IP 日计数 + 短窗计数；Redis 不可用时 fail-closed 拒绝——沿用断言防护的同款语义，不静默放行）

- 配置项全集 + `.env.example` 占位
- **测试**：额度原子扣减/并发/到量 429 语义（返回 error 帧或 200+error 帧，定一种写死）；成功计次/失败不计；IP 限流触发；Redis 故障 fail-closed；cap 白名单外 404；审计行写入（断言无原始 IP）；SSE 帧类型回归

## 验收标准

1. 未登录游客在 AI 中心可用三个体验表单各生成一次成功结果（SSE 流式），刷新页面 gtid 保持、剩余次数正确递减
2. 每 capability 第 4 次/天 → 引导注册弹层；换浏览器（清 cookie）可再用，但同 IP 全天累计 30 次后被 IP 层拒绝
3. provider 失败不扣额度；短窗 10/min 限流生效
4. 既有生成端点对未登录仍 401（fail-closed 回归）；登录用户体验面无变化
5. `guest_trial_run` 只有哈希 IP 与结果，无输入/产物/原始 IP；finance credits 与 ai_run 表零新增行
6. edge flag 关闭 → `/api/guest-trial/*` 404
7. 既有 intelligence 测试零回归

## 代码库陷阱清单（必读）

- Java 构建：JDK 25（`JAVA_HOME=/opt/homebrew/opt/openjdk@25`），入口 `platform-java/` 下 `./gradlew`
- **intelligence 没有全局 ObjectMapper bean**——持服务本地实例
- **SSE 帧里 boolean/number 必须原生下发**（`"false"` 字符串在 JS 是 truthy）；流已 200 开头后失败只能走 `{error}` 帧
- **多模态/文本调用是阻塞 IO**：boundedElastic，不进 WebFlux 事件循环；base64 图 ≤4MB 校验在进 buffer 前
- Reactor：`switchIfEmpty` 副作用包 `Mono.defer`；扣减/限流/审计顺序 = 限流 → 白名单 → 扣减预检 → provider → 成功计次
- Redis 故障 fail-closed（拒绝并记日志），不静默放行——镜像断言 replay 防护语义
- edge fail-closed：新前缀不进 RouteManifest 就是 404
- Jackson 3：请求 record 可选数值字段必须包装类型；`is` 前缀派生态加 `@JsonIgnore`
- 提交按语义拆分（建议：ADR / trial 面+额度+审计 / edge 路由 / 前端 / docs 各一个 commit），中文 commit message、`feat(scope):` / `test(scope):` / `docs:` 风格
