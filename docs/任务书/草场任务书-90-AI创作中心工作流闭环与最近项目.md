## 1. 目标与范围

### 1.1 一句话目标

让 AI 创作中心从“选择能力并生成”形成可恢复的项目工作区闭环：用户可从最近项目继续创作，门店/任务上下文、草稿、生成结果、助手和运行记录能够互相回跳。

### 1.2 背景与价值

`ai.html` 已提供文章、图片、视频、朋友圈、热点和素材等能力，但入口状态分散在路由 query、组件局部状态和草稿中。刷新或离开页面后，用户难以找到未完成项目，生成结果也缺少明确的保存和回到任务出口。本期复用现有 `creation_draft`，补齐最近项目索引与工作区状态，降低重复输入和结果丢失。

### 2.5 当前行为（FACT）

1. `AiCreationCenter` 根据 query 和导航状态切换能力；来源信息在局部状态中传递，离开页面后无统一最近项目入口。

3. 文章、图片、视频和朋友圈视图各自保存部分字段；视频结果与素材库、任务回跳没有统一出口。
4. 助手和运行记录面板可以独立打开，现有记录未强制关联 draftId。

### 2.6 当前问题

- 现状：深链来源在部分进入路径丢失；用户刷新后通常只能重新选择能力。
- 问题：草稿无法表达完整工作区，最近项目缺少统一索引；结果生成后下一步不明确。
- 影响：重复输入、未完成任务中断、生成资产孤立，尤其影响视频和门店任务场景。
- 根因：已有草稿模型只覆盖内容正文，路由、来源、步骤、结果和运行记录没有统一关联。

### 决策记录

#### D-01：复用 creation_draft 作为唯一工作区存储

- 决策：在现有草稿记录上增加结构化 `workspace` 字段和必要元数据，不创建 `recent_projects` 第二套表。
- 原因：已有账号隔离和乐观锁，避免双真相与迁移分叉。
- 放弃方案：新建项目表并同步草稿；会扩大权限和生命周期风险。
- 允许执行模型修改：否。

#### D-02：最近项目由服务端返回，客户端只做展示缓存

- 决策：最近项目列表按 `updatedAt` 降序由草稿查询接口返回；客户端最多缓存最近一次响应，不把 localStorage 作为权威。
- 原因：跨设备可恢复且遵循账号隔离。
- 放弃方案：仅 localStorage；无法跨设备且清理不可控。
- 允许执行模型修改：否。

#### D-03：保存采用节流自动保存 + 显式保存

- 决策：字段变更后 800ms 节流 PUT；离开页面前 flush；保存失败显示可重试状态，不阻塞继续编辑。
- 原因：减少请求并避免刷新丢失。
- 放弃方案：每次按键保存；请求噪声和竞态更高。
- 允许执行模型修改：否。

#### D-04：工作区只保存可恢复数据

- 决策：保存步骤、表单文本、来源 ID、结果资源 ID、运行 ID；不保存密钥、Cookie、data URL、签名 URL 或完整二进制。
- 原因：安全、体积和过期风险可控。
- 放弃方案：保存完整生成响应和图片 data URL；会造成泄露与超大 payload。
- 允许执行模型修改：否。

## 4. 目标行为

### 4.1 用户流程

1. 用户从 AI 中心、门店深链或任务深链进入，系统解析 `capability`、`storeId`、`taskId`，在页面顶部显示来源胶囊。
2. 用户填写文章/图片/朋友圈/视频内容；变更自动保存到当前 draft，右上角显示“已保存/保存中/保存失败”。
3. 用户离开后回到 AI 中心“最近项目”，列表显示能力、标题、来源、更新时间和状态；点击继续创作恢复工作区。
4. 生成完成后，结果卡提供“保存到素材库”“回到任务”“继续编辑”出口；保存结果只写资源 ID。
5. 助手建议和运行记录显示当前项目标识；失败时可重试或回到表单，不丢失已保存输入。

### 4.2 行为变化表

| 场景 | 当前行为 | 目标行为 |
|---|---|---|
| 门店/任务深链 | 部分来源选项不显示或刷新丢失 | 来源胶囊稳定显示，刷新保留，清除后回到普通创作 |
| 新建创作 | 无统一项目索引 | 首次有效输入创建 draft，进入最近项目 |
| 刷新/返回 | 局部状态丢失 | 恢复最近一次已保存步骤和字段 |
| 最近项目 | 无统一入口 | 按更新时间降序，支持继续和删除索引 |
| 生成结果 | 出口分散 | 统一保存素材、回任务、继续编辑按钮 |
| 保存失败 | 仅 toast 或静默 | 显示失败状态与“重试保存”，编辑仍可继续 |
| 助手/运行记录 | 可独立打开 | 带 draftId 关联并可回到当前项目 |

### 4.3 状态定义

`draftStatus` 沿用后端现有小写值：`draft`（有输入未生成）、`in_progress`（存在进行中运行或最近运行失败但仍可编辑）、`completed`（至少一个结果资源 ID）、`archived`（用户删除最近项目索引）。最近一次运行的 `runState`（`idle`/`running`/`succeeded`/`failed`）存于 `workspace_json`，不扩展既有 status 枚举。

`saveState`：`idle`、`saving`、`saved`、`error`。`saveState` 只属前端展示，不写入服务端状态枚举。

### 4.4 状态迁移规则

| 当前 | 触发 | 目标 | 备注 |
|---|---|---|---|
| 不存在 | 首次有效输入 | draft | 空表单不创建草稿 |
| draft | 发起生成 | in_progress + runState=running | 记录 runId |
| in_progress + runState=running | 生成成功且有资源 ID | completed + runState=succeeded | 保留输入和结果 |
| in_progress | 生成失败 | in_progress + runState=failed | 可重试 |
| in_progress + runState=failed | 修改输入 | draft + runState=idle | 清除最近错误但保留 runId 历史 |
| 任意非 archived | 删除最近项目 | archived | 不删除素材和任务数据 |

## 5. 业务规则

### 5.1 输入规则

| 字段 | 类型 | 必填 | 限制 |
|---|---|---:|---|
| `capability` | enum | 是 | `article`、`image`、`video`、`moments` |
| `title` | string | 否 | trim 后 1–120 字符；空值由能力+更新时间生成展示标题 |
| `storeId`/`taskId` | string | 否 | 仅保存服务端已授权 ID；非法或无权 ID 不写入 |
| `currentStep` | string | 是 | 由能力白名单决定，未知值归一为首步 |
| `inputs` | object | 否 | 结构化文本，序列化后整个 workspace ≤64KB |
| `resultAssetIds` | string[] | 否 | 最多 20 个，去重；只接受素材服务返回的 ID |
| `runIds` | string[] | 否 | 最多 20 个，去重；只保存运行记录 ID |

### 5.2 校验规则

1. 请求必须带当前登录账号；服务端按 accountId 查询，客户端传入 accountId 一律忽略。
2. `expectedVersion` 不匹配返回 409，客户端重新 GET 后合并本地未提交字段并提示用户。
3. `workspace` 非对象、枚举非法、超长或包含禁止字段（`secret`、`cookie`、`dataUrl`、`signedUrl`）返回 400，且不落库。
4. 结果 ID、任务 ID 和门店 ID 必须经过既有服务权限校验；校验失败不泄露资源存在性。

### 5.3 业务判断规则

```text
有效输入 = trim 后至少一个能力必需字段非空
若无有效输入：不创建 draft
若 draft 已存在：按 expectedVersion 乐观锁更新
若生成返回资源 ID：将 ID 去重后追加，状态置 completed、runState=succeeded
若删除最近项目：只置 archived，不删除资源、运行记录或任务
```

### 5.4 权限与业务不变量

- 用户只能读写自己账号的 draft；跨账号访问统一返回 404。
- 门店/任务来源仅作为 UI 上下文；任务权限和冻结快照仍由任务服务判断。
- 自动保存不得触发 AI 生成、积分扣减或素材删除。
- 同一 `runId` 重放不得重复扣费或重复追加资源 ID。
- API 响应不得返回密钥、Cookie、签名 URL、data URL 或完整 prompt 中的隐私字段。

## 6. 接口契约

### 类型与调用签名

```text
GET  /api/creation/drafts?limit=20&status=active
GET  /api/creation/drafts/{draftId}
POST /api/creation/drafts
PUT  /api/creation/drafts/{draftId}   (expectedVersion 必填)
POST /api/creation/drafts/{draftId}/archive
```

### 6.1 请求信息

所有接口要求登录，沿用 `grassland-http.ts` 和现有站内信封；请求 JSON，响应 HTTP 200/201/400/401/404/409。列表按 `updatedAt DESC, id DESC` 排序。

### 6.2 请求参数

创建示例（EXAMPLE）：

```json
{"capability":"article","title":"春季门店推文","workspace":{"currentStep":"editor","inputs":{"topic":"春季上新"},"source":{"storeId":"store_fixture_1","taskId":"task_fixture_1"}}}
```

更新请求必须带 `expectedVersion`；服务端只接受 §5.1 字段。`archive` 不接受额外 body。

### 6.3 成功响应

```json
{"success":true,"data":{"id":"draft_fixture_1","capability":"article","status":"draft","version":3,"workspace":{"currentStep":"editor","inputs":{"topic":"春季上新"},"source":{"storeId":"store_fixture_1"}},"resultAssetIds":[],"runIds":[],"updatedAt":"2026-09-07T10:00:00Z"}}
```

列表响应为 `data.items`，最多返回 `limit`（默认 20，最大 50）。创建返回 201；更新、归档和读取返回 200。

### 6.4 错误契约

| 状态 | `error.code` | 触发 | 调用方动作 |
|---:|---|---|---|
| 400 | `INVALID_WORKSPACE` | 字段非法、超长或禁止字段 | 展示字段错误，不重试原请求 |
| 401 | `UNAUTHENTICATED` | 会话失效 | 走既有登录流程 |
| 404 | `DRAFT_NOT_FOUND` | 不属于当前账号或已不存在 | 从列表移除，不泄露原因 |
| 409 | `DRAFT_VERSION_CONFLICT` | expectedVersion 过期 | GET 最新版本，提示合并 |
| 429/5xx | 既有网关错误 | 服务暂时不可用 | 指数退避最多 3 次，仍失败显示重试 |

### 6.5 错误处理原则

自动保存失败不丢本地编辑态；页面卸载前只同步 flush 一次。请求取消不显示错误 toast。所有错误通过统一 `readError` 解析，禁止裸 `throw` 影响页面。

### 6.6 契约不变量与观测要求

- 每次 PUT 最多一次数据库写入；重试使用同一 draftId 和最新 version。
- 列表不返回 `workspace.inputs` 中被服务端标记为敏感的键。
- 记录 `draft.save.success`、`draft.save.conflict`、`draft.save.error` 计数，日志只含 accountId、draftId 和 code，不含内容。

### 6.7 流式、上传与异步任务契约

AI 生成流式协议不变。本任务只在生成开始、成功、失败三个既有回调点写入 runId/status；不保存流式 token，不改上传和预签名 URL 协议。

- AC-101：Given 旧草稿行，When 使用旧请求读取/更新，Then 200 且正文不变，新字段按默认值补齐。
- AC-102：Given 两个客户端使用同一旧 version，When 并发 PUT，Then 一个 200 一个 409，数据库只有一次成功更新。
- 测试：`TC-C02-001` CRUD、`TC-C02-002` 旧行兼容、`TC-C02-003` 敏感字段/64KB、`TC-C02-004` 跨账号、`TC-C02-005` 并发；V-003、V-004。
