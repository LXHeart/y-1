## 6. 任务卡

### 卡 A:用户列表富化、筛选与查看类权限放宽
**背景**:列表接口已返回 status/roles 但前端未展示;身份与组织归属(identity_profile/organization)治理台不可见;查看类权限目前 admin 独占,客服/风控无法查账号。

**改动文件**:
- 修改 `platform-java/services/identity-service/src/main/java/com/grassland/identity/admin/AdminUserRepository.java`
- 修改 `platform-java/services/identity-service/src/main/java/com/grassland/identity/admin/AdminUserController.java`
- 新建 IT `platform-java/services/identity-service/src/test/java/com/grassland/identity/admin/AdminUserListingEnrichmentIT.java`(命名以目录既有风格为准)

**开始前检查**:
1. `git status` 干净;卡面所述文件与实际路径一致。
2. 核对 organization_membership 当前列集(找 V2 之后所有 member 相关迁移),确认账号→组织归属的正确查询列。
3. 核对既有 AdminUser IT 的造数手法(直插 SQL 先例),新 IT 照抄造数方式。

**参考代码**(现状,直接相关):
```java
// AdminUserRepository.findAll —— 本卡在此 SQL 上扩展
SELECT id::text, email, display_name, role, status, created_at
  FROM app_users
 %s
 ORDER BY created_at DESC
 LIMIT :limit OFFSET :offset

// AdminUserController.listUsers 门禁(本卡换):
accounts.requireAdmin(request)   →   accounts.requireRole(request,
        BackendRole.PLATFORM_ADMIN, BackendRole.CUSTOMER_SERVICE, BackendRole.RISK)
```

**做法**:
1. `AdminUserRow` record 增加四个字段:`hasRecommender`/`hasMerchant`/`hasMembership`(boolean)、`ownedOrgNames`(String,可 null)。
2. findAll 的 SELECT 增加四个标量子查询(与既有 searchPredicate 拼接风格一致,全部挂同一 FROM):
   - hasRecommender:`EXISTS(SELECT 1 FROM identity_profile p WHERE p.account_id = app_users.id AND p.identity_type = 'recommender')`
   - hasMerchant:同上 `identity_type = 'merchant'`
   - hasMembership:`EXISTS(SELECT 1 FROM organization_membership m WHERE m.account_id = app_users.id)`(若开始前检查发现 membership 有 active/软删列,谓词按实际语义收紧并在报告里注明)
   - ownedOrgNames:`(SELECT string_agg(o.name, ', ') FROM organization o WHERE o.owner_account_id = app_users.id)`
3. 新增可选筛选参数(拼入 searchPredicate 同一片段或并列 WHERE,保持 findAll/countAll **同口径**):`status`(精确匹配 app_users.status)、`identityType`(recommender/merchant/member 三值,member=hasMembership 为真;非法值 400)。countAll 同步。
4. listUsers 签名增加 `@RequestParam(required = false) String status` 与 `identityType`,透传 repository;校验非法 identityType 抛 IllegalArgumentException(既有 handler 已转 400)。
