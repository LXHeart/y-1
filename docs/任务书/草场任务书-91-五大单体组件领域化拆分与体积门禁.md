## 3. 技术决策（已定案，执行期不得更改）

#### D-01 纯重构红线

行为零变更、既有测试用例零改动、DOM 锚点（data-testid/data-test/class/aria）逐字符保留。验收=既有测试全绿 + 行数达标。唯一豁口=§4.2 Admin 三条声明差异（拍板 3 授权）。

#### D-02 Workbench script 拆四个 composable，工厂参数注入，不引全局 store

`useWorkbenchUrlState` / `useWorkbenchNavigation` / `useWorkbenchAccountLifecycle` / `useTaskFormDrawer`，全部为 `(deps) => ({...})` 工厂，deps 传六域 composable 实例与 route/router/emit。禁止模块级共享 refs（会破坏测试隔离）。

#### D-03 Workbench 模板面板走 provide/inject 上下文，v-show 语义在外层保留

`src/views/grassland/workbench-keys.ts` 导出类型化 InjectionKey；MerchantTasksPanel/TaskApplicantsPanel/RecommenderEngagementsPanel 注入六域实例与关键 refs，不走 20+ props 钻透；**子组件禁止自行 `useGrassland()`**（非单例，error/loading 会分叉）。tasks/org/finance 六个子区块与 org/finance 内部小节的 v-show 留在 GrasslandWorkbench 模板原位。

#### D-04 Admin 终态统一渲染 = registry 单路径 + KeepAlive(include=六新面板)

23 页签全部经 298–303 通用渲染器 `<component :is>`；渲染器外包 `<KeepAlive :include="ADMIN_STATEFUL_TABS">`，include 仅含六个新面板（`defineOptions({name})` 显式命名）。**外部 17 面板不进 include**（维持现状卸载语义，且避免长驻轮询泄漏）。生命周期等价表：users/kyb=onMounted 拉一次（切回不重拉）；recommenders/tasks/finance=onActivated 拉（每次激活重拉，等价现状 onActivate）；状态经 KeepAlive 常驻（等价现状父级 refs 常驻）。

#### D-05 registry 纯数据化：badge/onActivate 过渡为 AdminView 本地映射表，随卡片逐段消亡

A1 将 TAB_REGISTRY/ADMIN_GROUPS/ADMIN_TAB_KEYS/TAB_ROLES/守卫移入 `src/ops/admin/adminTabs.ts`（纯静态数据 + 静态 import 23 组件，无闭包→无 TDZ）；badge/onActivate 字段从 registry 删除，AdminView 持本地 `BADGE_SOURCES`/`ACTIVATION_HOOKS` 映射（行为与现状逐点等价）；A2–A4 每抽一面板就把对应映射项迁入面板（onMounted/onActivated/控制器注册），A4 末两映射表删净。

#### D-06 Video 子组件纯 props/emit，vm 绑定留在视图

`useVideoProduction`/`useVideoReference` 的解构全部留在 VideoProductionView（测试写 `vm.images`/`vm.form.*`/调 `vm.generateStoryboard()`）；UploadStage 表单七字段用 per-field emit（`@update:shopName="form.shopName = $event"` 式），父模板 7 行接线——**禁止子组件内 v-model 直改 form prop**（`vue/no-mutating-props` lint 必挂，#68 D1 实锤）。form 是同一 reactive 对象，测试经 vm 赋值后子组件 `:value` 正常响应，行为等价。

#### D-07 Article 阶段组件 props/emit + `<style scoped src>` 共享样式

`src/views/article/stage-shared.css` 承载 `.stage-card/.card-head/.btn-*/.action-row/.fade-in` 等跨阶段原语，各子组件与视图用 `<style scoped src="./stage-shared.css"></style>` 引入（Vue SFC 标准特性，scoped 语义对引入内容同样生效）——避免每个子组件复制一份。阶段组件单根节点=原 `<section class="stage-card gl-zone fade-in">`，`v-if="stage === 'xxx'"` 挂在组件标签上，DOM 字节等价。

#### D-08 Image 只拆模板与样式，不拆逻辑域

script 域不动（已薄）；AnalysisControlCard/AnalysisResultCard/StepReviewCard 为 props/emit 视图组件；重复编辑表单抽 `AnalysisEditForm.vue`（×2→1）、进度步骤抽 `GenerationStepsList.vue`（×3→1）。样式随迁为主。

#### D-09 体积门禁：`.vue` ≤800 硬顶 + 四文件豁免（只减不增）+ composables 仅监控

`scripts/check-file-size.mjs`：`src/**/*.vue` >800 即 exit 1；豁免数组=[DisputeDetailView.vue, AiCreationCenter.vue, MerchantKybCard.vue, PrecedentLibrary.vue]（豁免项超现值即红，只减不增）；`src/**/composables/*.ts` >500 只打印 WARN 不红（useVideoProduction 1002 等六个超标留待后续批次）。接入 `npm run lint` 末步；G1 最后执行（避免拆分中被自己拦截）。

#### D-10 样式随迁原则
