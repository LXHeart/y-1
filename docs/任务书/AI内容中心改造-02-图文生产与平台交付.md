## 1. 完成后用户能做什么

用户可从真实资料、现有文章或照片进入，制作小红书图文、抖音图集、点评内容、公众号编辑稿、知乎回答/文章和朋友圈图片文字。图卡可逐页编辑与重试，离开后可恢复；完成页将正确版本的正文、封面、图片顺序、来源和声明组成可导出的成品。

## 2. 工作范围与顺序

| 子项 | 实施内容 | 独立验收结果 |
| --- | --- | --- |
| 2.1 图卡身份与执行可靠性 | `cardId/position/role` 贯穿计划、编辑、生成、重试与持久化；补任务冻结执行；建立可查询的生成操作记录 | 第 3 页重试仍是内容页且保留风格；错配任务在调用前拒绝；相同操作不重复生成 |
| 2.2 图文主流程与恢复 | 图卡状态提升至工作流，接入正式步骤与项目恢复；区分仅文案和完整图文；实拍排序复用相同结果协议 | 切换步骤或刷新不丢计划和成功图片；完整图文含用户选定媒体 |
| 2.3 已有内容加工 | 开放 create/adapt/format；短笔记减少不必要步骤；已有正文和图片直接进入改编、排版或整理 | 原文排版保持文本，改编保留来源并显示重要变更，快速创作沿用计费入口 |
| 2.4 平台编辑稿补齐 | 知乎问题/开头/标题分字段校验；公众号摘要/封面/富文本；抖音逐图文案/描述/话题分开；朋友圈保留共用短文案和图片顺序 | 各图文形式有可编辑且字段完整的发布材料 |
| 2.5 公共完成页与图文导出 | 实现任务 1 确定的交付契约、readiness 检查器、联合预览及图文导出服务；补声明、来源回跳和旧版本导出 | 图文流程形成端到端成品；公共组件和服务可由任务 3 接入视频 |

## 3. 各平台最低交付

| 平台/形式 | 必须能编辑、恢复和导出的内容 |
| --- | --- |
| 小红书图文 | 标题、正文、独立话题数组、封面、有顺序的实拍或图卡、来源与声明 |
| 抖音图集 | 首图、逐图内容、发布描述、话题；图内文字与发布描述独立保存 |
| 大众点评图文 | 按真实身份组织的评价/笔记/经营介绍、实际感受和图片顺序；适用时才有标题 |
| 公众号 | Markdown 原稿、经过清理的富文本、摘要、封面、正文图片、来源及分享配文；短通知按实际内容交付 |
| 知乎回答/文章 | 问题、回答开头或文章标题、正文、可定位的用户资料引用、适用边界和声明 |
| 朋友圈图片文字 | 共用短文案、有顺序的图片、可选每图文字或编辑备注、适用声明 |

任务 1 提供点评事实与身份约束，本任务负责它们进入完整成品。资料引用先使用用户提供并确认的内容，自动联网检索留待后续。

## 4. 关键契约与异常行为

- 图卡数量首期沿用服务端最多 9 张。请求校验 ID 唯一、位置和角色合法；单卡重试按原 `cardId` 合并，排序/删除不改变结果归属，响应不得使已删除卡片重新出现。
- 封面由 `role=cover` 决定，不由本次请求数组索引决定；风格锚在内容页重试时仍注入。图片参考不属于本批默认能力。
- 计划阶段复用 `GraphicTaskCreationContext.bind` 和冻结文本执行；生图复用 `TaskImageGenerationService.generateForBoundContextTraced`，purpose 继续为 CARD_SERIES；独立模式使用既有独立执行路径。
- 本任务明确包含总方案 §8.4 第 7 项的操作记录，使 T21 可在本批完整验收：`owner + requestId` 唯一，执行前占位，关联请求摘要、卡片身份、runId、状态和结果。同键同请求回读原结果，变更请求返回 409。
- 网络超时先查询操作；供应商受理后结果不可核实时保持待确认。操作记录本身不证明供应商能保证一次执行，不能把待确认自动当作失败再次扣费。
- 成功图片先 persist 取得永久引用，再存草稿；素材登记失败单独重试。保存、登记或下载失败均不触发重新生图。部分失败保留已成功页和每页错误。
- `format` 不调用改写/总结，不因容量不足偷偷删文；允许增加页面或提示用户明确决定。当前字图一体模型无法保证逐字准确的卡片，不得标为“原文不变”的精确排版成品；本批可交付原文富文本、媒体排序和素材包。
- W09 的精确可编辑图卡是后续模式，本任务继续保留字图一体方案。需要把长文提炼成少量卡片时明确使用 `adapt`。
- 知乎开头、问题和文章标题使用各自规则；旧 `title` 参数在 API 边界适配。风格修改不增加作者资历或修改价格、数字与事实。
- 富文本优先复用 `marked`、`DOMPurify`；处理外部 HTML、链接和图片时遵守授权与清理规则。公众号在本批交付编辑稿和素材，不宣称已同步平台草稿箱或保证所有目标编辑器远程图片可直接使用。
- 图文导出拟新增 `POST /api/creation-drafts/{id}/exports`，按指定草稿版本、格式及授权结果生成；临时下载地址不存 workspace。请求和响应在 2.5 编码前按任务 1 的交付契约确定并补网关路由验证。
- `completed`、发布包 `readiness`、公开发布分别判断；失效媒体或必要字段缺失时指出缺项。修改正文后保留旧图卡，提示相关素材待复核，用户决定更新范围。
