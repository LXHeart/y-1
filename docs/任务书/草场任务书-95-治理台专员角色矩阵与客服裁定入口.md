### 6.2 `GET /api/admin/trust/disputes/{id}`（新增，trust）

```text
成功：HTTP 200 {"success":true,"data":{ …详情体… }}
错误：HTTP 404 {"success":false,"error":"争议不存在"}；HTTP 403 无角色（既有断言信封）
```

详情体字段（实现沿用列表 `toBody` 手法逐字段 put）：

| 字段 | 来源 | 处理 |
|---|---|---|
| id / engagementRef / organizationId / openedByRole / status / kind / appealState / premiumSupport / supportPriority / supportBadge / createdAt / updatedAt | 同列表 `toBody` | 原样 |
| openedByAlias | `redactor.pseudonym(id, openedByAccountId)` | 假名 |
| respondentAlias | `redactor.pseudonym(id, respondentAccountId)`（null → `participant-unknown`，与 `pseudonym` 空参语义一致） | 假名 |
| reason / decision / finalDecision | `redactor.maskText(...)`（null 透传 null） | 脱敏 |
| finalDecidedByAlias | `redactor.pseudonym(id, finalDecidedBy)`（null → null） | 假名 |
| channel | `effectiveChannel()`（`cs_direct`/`court`） | 派生 |
| csDueAt / taskPlatform / round / version / decidedAt / evidenceDeadline / claimantDoneAt / respondentDoneAt / respondentAnswered | 记录列 | 原样 |
| evidence | `evidenceRepo.listByDispute(id)` → `redactor.redact(...)` | 内联脱敏列表（id/kind/caption/content/submittedByAlias/submittedByRole） |
| evidenceSummary | `redactor.summary(...)` | 条数摘要 |

时间戳序列化与列表端点现状一致（记录里为 `Instant`，随既有 Jackson 配置输出）。**不回**：`openedByAccountId`、`respondentAccountId`、`finalDecidedBy`、`evidenceRef`、`version` 之外的其他内部列。
