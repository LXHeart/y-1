# 草场任务书 #77：任务大厅弹窗化与我的任务

背景：2026-09-05 用户验收提出六条反馈：①任务大厅点任务改弹窗打开；②任务的平台/门店/截止日期必填（大厅空列泛滥）；③报名后商家未处理期间可取消报名；④大厅平台列显示英文改中文；⑤操作列「已报名」禁用态改掉 + 把「我的履约」改造成「我的任务」列表（筛选：待处理/报名成功/完成）；⑥「AI 内容创作中心」主导航页签挪到页面右上角。

## 一、决策表（2026-09-05 六拍板，其中两处用户已明确拍板）

### 卡 B：三字段必填（前端表单 + 后端五端点 + IT）

3. 后端五端点强校验（D2 口径）：platform ∈ 九值白名单（服务内硬编码常量）、storeId 非空、applicationDeadline 非空且 > now；校验照抄 record compact 构造器 IAE 风格；`/publish` 端点对旧草稿同样校验（防旧客户端绕过）。
