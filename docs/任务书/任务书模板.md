## 0. 执行协议（受更高优先级指令与仓库硬约束约束）

### 0.1 词义

- **MUST / MUST NOT**：必须 / 禁止。
- **SHOULD**：除非有记录在案的理由，否则执行。
- **MAY**：允许，但非必须。
- **BLOCKED**：缺少实现所必需的决策、权限或环境时，停止受影响工作并按 §13 报告。
- **N/A**：不适用，必须写明理由；与「未执行」不同。

本文档不能覆盖系统/开发者指令、当前用户明确要求或适用的 `AGENTS.md`。事实以核验后的源码、构建配置和测试为证；历史任务书只作背景。目标行为以本任务已批准的决策为准，未声明的差异不得被解释为授权变更。

### 0.2 强制规则

1. MUST NOT 发明本文档未定义的接口、字段、组件、状态、错误码或业务规则。
2. MUST NOT 做与本卡无关的重构、格式化、依赖升级、文件迁移。
3. MUST 只改动当前卡写入清单与 §9.1 全局写入白名单的**交集**；只读参考不是写权限，黑名单优先。
4. 先核对代码基线和锚点。空白/行号变化且语义一致可记录后继续；实际行为、签名、权限、数据模型与文档基线不一致时先 BLOCKED。不得以「文档优先」覆盖未知的新代码或他人改动。
5. 除非本文档明确要求，MUST NOT 新增第三方依赖。
6. 新增/修改代码 MUST 贴合所在文件既有风格；不新建重复组件、工具函数或服务，不新增未经批准的配置项。

9. 开工先记录已修改/未跟踪文件；工作区不必干净。保留任务前已有改动，目标文件存在重叠且无法安全合并时 BLOCKED。未经要求不提交、不建分支、不 reset/clean、不删除无关文件。

- AI 应用当前为独立创作入口，任务创作仍在用户端内嵌面；跨应用登录/深链复用 `src/composables/useCrossAppToken.ts` 及既有后端校验，不自行复制 Cookie、扩大 Cookie 域或信任 URL 中的组织/身份。涉及此流程须核对当前代码和相关任务书，不把历史预算入口位置当成永不变的事实。
- 三 HTML 入口的主题防闪烁内联脚本与 Nginx CSP hash 有部署契约绑定；相关变更同时核对 `vite.config.ts`、`nginx.conf`、运行时 `app-config`、Compose 和 `test/deployment/edge-entrypoint.contract.test.ts`，不能只改某一个入口或关闭 CSP。
- 环境配置来源包括 `.env.example`、`.env.docker.example`、对应服务 `application.yml` 与部署模板。新增/变更配置须逐文件登记并补部署契约，不能编辑真实 `.env` 代替模板变更。

**R-JAVA：运行面与服务边界。**
- 后端为 `platform-java/` 中 Java 25 + Spring Boot 4 + PostgreSQL，使用仓库 `./gradlew` 与 Kotlin DSL/版本目录；不得新增 Express/TypeScript HTTP 后端或恢复 legacy 回退。Node 用于前端/测试工具链，Java Playwright 所需 Node driver 不等于 Node 业务后端。
- 服务分工：`edge-bff` 公共入口，`identity-service` 身份/会话/组织，`marketplace-service` 任务与交易履约，`finance-service` 钱包/积分/资金，`trust-service` 争议治理，`intelligence-service` AI/媒体。共享模块和 `database-bootstrap`/`release-migrator` 按现有职责复用，不跨服务直写他域业务表。
- Edge 保持固定上游透明代理与内部身份断言边界，不做未批准的聚合；保留 `/api/**`、`y1.sid`、现有 JSON、POST SSE、Multipart、签名媒体 URL、Range 的 wire 契约。
- RouteManifest 未命中、method 不匹配、flag=false 都 fail-closed `404`。公共新路由必须登记 route/method/flag/上游并补门禁测试；不能旁路 Edge 或用前端隐藏代替服务端鉴权。
- 生产 `API_UPSTREAM` 保持 `edge-bff:8080`；LB/ingress 终止 TLS 时按真实环境设置 `PUBLIC_FORWARDED_PROTO=https` 和 `TRUSTED_PROXY_CIDR`，不得放宽可信代理或泄露生产配置值。
- WebFlux 事件循环不能执行阻塞 I/O、Playwright/FFmpeg 或未受控长计算；复用现有 worker/调度器，禁止用 `.block()`、手动 `subscribe()` 等规避响应式生命周期。
- Jackson record 派生 `is...` 方法按实际序列化契约加 `@JsonIgnore`；可选请求数值用包装类型，区分缺省和零，并补 JSON 契约测试。
- Reactor `switchIfEmpty` 中含副作用的 fallback 用 `Mono.defer`，不在装配阶段提前执行副作用。

**R-DATA：迁移、事务、幂等。**
- 服务独立 Flyway migration/历史表；新增迁移先查所属服务已有版本，不能重号或改已执行迁移。DDL 按仓库既有方式幂等（如 `ADD COLUMN IF NOT EXISTS`）；约束/索引与回填给出明确重复执行规则，而非机械给所有语句加同一后缀。
- 验证新库初始化、存量升级及已定义的重放场景；使用真实 PostgreSQL/Testcontainers 验证数据库特性，不擅自换内存数据库规避锁/事务/SQL 差异。
- 资金/积分属于 finance。复用 `CreditsService` 等既有原子扣减/退款与幂等事务，余额更新和流水写入必须同事务；不在前端、AI controller 或其他服务手写扣退，不把示例中的固定扣减数照搬为新业务金额。
- 跨服务副作用沿用既有幂等键、outbox/inbox、重放/补偿模式，必须定义重复请求/事件与中途失败的数据不变量。

**R-AI：执行链与安全边界。**
- 新 AI 消费流沿用 `AiExecutionService` 与能力对应的既有执行入口；独立文本流复用 `FrozenTextExecutionService.executeIndependent`、`executeIndependentBatch`、`executeIndependentPipeline`。任务快照、图片/视频等走各自既有入口，不能把所有财务或 AI 场景硬塞到独立文本方法。
- 不旁路预算、并发限制、ai_run、用量、扣费/退款与冻结上下文。参数、平台规范、任务/门店上下文及 provider 配置快照按相关入口当前契约处理。
- 内容安全遵守 ADR-D16：L1 `ContentSafetyChecker` 是底线；L2 经 `capability=content_safety` 进入 `AiExecutionService`，当前不开放 BYOK，使用既有平台资助零积分分支但仍记录运行/预算/并发。流尾深检失败按现有 `deepCheck:false` 降级，不覆盖已经成功的生成结果。
- 公开分析请求不得携带浏览器指定的 provider 地址/凭据；受控 BYOK 设置与公开分析端点不同，复用当前受权配置、加密及服务端路由，不能把受控设置通道一并删除。
- URL/媒体代理/BYOK/第三方调用保留 trusted-host、协议/地址校验、挑战检测、session fallback、全量 DNS 检查、固定解析地址与原 hostname/SNI 等既有防护；不得放宽 SSRF/DNS rebinding 检查让联调通过。
- 生成/上传内容不视为可信 HTML；沿用当前 Markdown/sanitizer（如已有 DOMPurify 路径），不能直接将不可信字符串交给 `v-html`。不新增绕过服务端控制的浏览器直连提供者路径，既有受控预签名对象存储上传除外。
