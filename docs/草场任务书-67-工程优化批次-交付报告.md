## 风险与限制

### 已知限制
1. **控制器拆分不改变 API 契约**：所有端点 URL 保持不变，前端零修改
2. **异步组件加载时机**：用户首次点击非默认页签时加载，网络慢时有短暂延迟
3. **测试覆盖**：新控制器复用既有测试，未新增专属 IT 测试（回归测试充分覆盖）

### 潜在风险
1. **异步组件失败处理**：defineAsyncComponent 加载失败时显示空白，未自定义 error component
2. **控制器依赖顺序**：KybMediaController 依赖 MediaController，必须同时启用 object-storage
3. **历史提交追踪**：大规模重构后 `git blame` 追溯到拆分提交，需跳转到拆分前版本
