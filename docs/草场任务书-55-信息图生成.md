## 模型与关键技术真相（动手前必读）

1. **dompurify 3.4.13 已在 dependencies**（package.json）——零新增依赖，前端净化直接用。
2. **SSE 文本流先例**：moments（`MomentsGenerationService.java:104` executeIndependent + 帧序 + 安全尾帧）——信息图镜像此姿态。帧序：prepare / progress（阶段文案）/ result（SVG 全文）/ safety 尾帧。
3. **kind CHECK**：V54 DO 块重建加 `infographic`（V43 模式，幂等；V 号若被占用顺延取空号）。
4. **lineage 姿态**：SSE 流用 `TextCreationLineageService.recordAdvisory`（吞错不破坏内容流、游客跳过——moments/comedy/article 先例）。
5. **素材库上传链既有**：presigned 三步上传（ContentAssetController + MediaLibraryPanel 先例），保存=上传前端导出的 PNG。
6. **canvas 导出注意**：SVG 需显式 width/height 才能可靠 drawImage（进 prompt 契约）；字体用系统栈白名单（见 S1.2），禁外部字体引用——外部引用既拖垮导出也构成注入面。
7. **前端矩阵**：`resolveWorkflow`（ai-platform-capabilities.ts:139-164）graphic 分支按 graphicWorkflow 分发；参数由 #54/#55 先落地者引入，后落地者复用取并集。
8. **估算口径**：输出 token 给足（SVG 冗长，建议 8192 上限）；输入按要点数与行数据量估。ImageAnalysisService 的估算公式形态可参照。

## S1 · 后端（intelligence-service 新包 `infographic/`）

### S1.1 V54 迁移

`V54__creation_generation_infographic.sql`：V43 同款 DO 块重建 kind CHECK 加 `infographic`。

### S1.2 prompt 契约（`InfographicPrompts`）——SVG 规范写死在系统提示

- 根元素 `<svg>` 带 viewBox 与**显式 width/height**；三尺寸预设：768×1024（3:4）/ 1024×1024（1:1）/ 768×1366（9:16）。
- 只允许基础元素：rect/circle/ellipse/line/polyline/polygon/path/text/tspan/g/defs+linearGradient。
- 字体栈白名单：`"PingFang SC","Hiragino Sans GB","Microsoft YaHei",sans-serif`。
- **禁**：script/foreignObject/事件属性（on\w+=）/外部 href（图片、字体、任何 http 引用）/data: URI 外链。
- 色值只从模板 palette hex 集合取（模板描述词随请求注入）。
- **关键数据逐字引用**：价格/时间/地址/品名必须与输入完全一致，系统提示显式声明「不得改写、缩写或虚构任何数字与地址」。
- 输出包 ```svg code fence，解析剥壳（既有 stripCodeFence 惯例）。

### S1.3 `InfographicService` + `POST /api/infographic/generate`（SSE）

- 输入组装（模板描述词 + 用户结构化输入）→ `executeIndependent(INFOGRAPHIC_GENERATION, …)` → SSE 帧序 + 安全尾帧 + `recordAdvisory(kind=infographic, result={svg, layoutId, styleId, size})`。
- **服务端最小注入校验**（纵深一层，前端 dompurify 仍是主闸）：LLM 输出命中 `<script` / `on\w+\s*=` / `xlink:href\s*=\s*"http` / `href\s*=\s*"http` 之一 → 502「生成结果未通过安全校验，请重试」，不落 lineage。
- SSE error 帧契约与 moments 一致（402/502/超时）。

### S1.4 后端测试（IT）

帧序与 result 帧 SVG 载荷；积分扣减 + 402 拒绝；**注入样本**（含 script/事件属性/外链的三份 SVG）被服务端 502 拒绝；kind advisory 落库（登录用户）与游客跳过；BYOK 文本键路由命中（回归性断言，确认走既有 text 链）。

## 实现红线（历史教训，逐条自查）

- 新流一律 `executeIndependent` 接入，禁手写扣退。
- `switchIfEmpty` 参数与副作用调用包 `Mono.defer`。
- 请求 record 可选数值字段用包装类型；派生态 is 前缀无参方法 `@JsonIgnore`。
- 迁移 DO 块幂等；迁移号冲突顺延取空号。
- 自建 WebTestClient 必带 30s responseTimeout。
- SSE 流错帧不吞安全尾帧（appendSafetyFrame 语义照抄既有五条流）。
