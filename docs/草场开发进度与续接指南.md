## 一、项目定位

草场（Grassland）：连接商家与推荐官的营销内容撮合平台。
原为 Vue 3 + Express TypeScript 单体，正在按 **Strangler Fig 模式**渐进迁移到 Java 微服务。

- 旧库（根目录 `server/`、`src/`）：仍承载全部业务，**不要改动其行为**
- 新库（`platform-java/`）：草场领域新代码的落点
- 迁移安全机制：`edge-bff` 用 RouteManifest 逐路由切换，每条路由有 `enabled` 开关，可零重启回滚到 Express

### Epic 2 Slice 2K：BFF 内部身份断言签发（HLD 7.4）
- **共享契约模块 `platform-identity-assertion`**（镜像 platform-storage）：`IdentityAssertion` record（claims：account_id/active_identity_type/session_token/auth_method/auth_strength/reauthenticatedAt/request_id/trace_id/audience/issuedAt/expiresAt）+ `IdentityAssertionCodec`（Jackson + base64url，前向兼容忽略未知 claim）+ `IdentityAssertionSigner`（HMAC-SHA256 token `<payload>.<mac>`，`MessageDigest.isEqual` 常量时间比较，expiry+audience+leeway 校验，任何失败返回 empty 不抛）+ `IdentityAssertionProperties`（enabled 时强校验 secret）+ autoconfigure（signer bean，opt-in）
- **edge-bff 签发**：`EdgeR2dbcConfig`（@ConditionalOnProperty `edge.identity.from-database-url`，从 DATABASE_URL 派生只读 ConnectionFactory；排除 Boot `R2dbcAutoConfiguration` 自管，未启用时纯代理启动）+ `EdgeCookieSigner`（Node 兼容 unsign，局部不共享 identity bean）+ `SessionIdentityResolver`（cookie→sid→session.sess.user.id→app_users→identity_session.active_identity_type；任一空=匿名）+ `InternalAssertionFilter`（WebFilter：所有请求剥离 denylist 伪造头，仅内部 Java 上游签发并附加 `X-Grassland-Identity`，匿名/legacy 不附）+ `UpstreamResolver.isInternalUpstream`（命中 route 上游 ≠ legacy default）
- **identity-service 消费（additive）**：`CurrentAccountResolver.resolvePrincipal` 优先信任断言头（验签通过即跳过 session 表 JSON 读取，account role/status 仍自查 app_users——identity 是权威），失效/缺失回退 cookie；既有测试（cookie、无断言头）零回归
- **断言格式**：自定义紧凑 HMAC（非 JWT），零新依赖、与 CookieSigner 一致；内部契约不需第三方互操作
- **compose env**：edge-bff / identity-service 共享 `IDENTITY_ASSERTION_SECRET`（默认复用 SESSION_SECRET 保证一致）+ `IDENTITY_ASSERTION_AUDIENCE`；edge-bff 新增 `DATABASE_URL`/`SESSION_SECRET`/`EDGE_IDENTITY_FROM_DATABASE_URL=true`
