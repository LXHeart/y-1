## 一、项目定位

草场（Grassland）：连接商家与推荐官的营销内容撮合平台。
原为 Vue 3 + Express TypeScript 单体，正在按 **Strangler Fig 模式**渐进迁移到 Java 微服务。

- 旧库（根目录 `server/`、`src/`）：仍承载全部业务，**不要改动其行为**
- 新库（`platform-java/`）：草场领域新代码的落点
- 迁移安全机制：`edge-bff` 用 RouteManifest 逐路由切换，每条路由有 `enabled` 开关，可零重启回滚到 Express

## 二、已完成并验证（截至 2026-07-22）

### Epic 0/1：Java 平台骨架
- Gradle Kotlin DSL 多模块，版本目录 `platform-java/gradle/libs.versions.toml`
- JDK 25、Spring Boot 4.1.0、Spring Cloud Gateway 2025.1.2
- 6 个模块：`edge-bff`、`identity-service`、`marketplace-service`、`finance-service`、`trust-service`、`intelligence-service`（后四个仅 health）
- `settings.gradle.kts` 已配 **阿里云 Maven 镜像**（国内网络必需）
- Dockerfile 采用 **预构建 bootJar** 模式（容器外构建，不在容器内 build）

### Epic 2：认证路由全部迁移到 identity-service
6 条 `/api/auth/*` 路由已迁完，真实 neon PostgreSQL 验证通过：

| 路由 | Controller |
|------|-----------|
| GET /api/auth/me | `MeController` |
| POST /api/auth/login | `LoginController` |
| POST /api/auth/logout | `LogoutController` |
| GET /api/auth/captcha | `CaptchaController` |
| POST /api/auth/send-code | `SendCodeController` |
| POST /api/auth/register | `RegisterController` |

**关键兼容性（已端到端验证）：**
- Cookie 签名：Node `cookie-signature` ↔ Java HMAC-SHA256 base64，互通
- Session 格式：Java 写 `connect-pg-simple` 格式的 session，Express 路由（credits/settings）能正确读取
- 验证：Java 登录 → Express `/api/credits/balance` 返回 `balance:3` ✓

### Epic 3 Slice 3A：事件基础设施
- **Kafka**（apache/kafka KRaft，:9092）+ **Redis**（:6379）已加入 compose
- **Outbox 模式**：`RegisterController` 同事务写 `outbox` 表 → `OutboxPublisher` @Scheduled(2s) 轮询 → KafkaTemplate 发到 topic `grassland.identity.events` → 标记 `published=true`
- 端到端已验证：注册 → outbox → kafka topic 收到 `UserRegistered` 事件 ✓

## 三、当前运行状态

```bash
docker compose ps   # 应看到 6 个容器
# y-1-backend (Express :3000)、y-1-frontend (Vue)
# y-1-edge-bff (:8080)、y-1-identity-service (:8082)
# y-1-kafka (:9092)、y-1-redis (:6379)
```

启动命令（含 Java 栈）：
```bash
docker compose --profile java-edge up -d
```

构建 Java 服务（容器外构建，再 up）：
```bash
cd platform-java && ./gradlew :services:edge-bff:bootJar :services:identity-service:bootJar
cd .. && docker compose --profile java-edge up -d --build edge-bff identity-service
```
