## 首版同条件对比（历史记录）

- 相同的 5.0344375 秒中文语音：草场把牧场带到每一块屏幕，这一季与我们同行。
- 相同音频主时钟、相同规则嘴型；两张 640×480 Canvas。
- A：原创程序绘制的 2D 人物，改变嘴型几何，加程序眨眼／呼吸。
- B：真实固定机位眨眼短片，手工标定一个嘴部区域，像素形变加合成口腔／牙齿。没有人脸检测、追踪、生成模型或外部渲染请求。
- 嘴型由这段已知文本的手工拼音表生成，并按音频能量累计值分配时间。**不是通用汉字转拼音实现，不是强制对齐，不是来自 TTS 的音素时间戳。** 音量基线使用同一能量数组。
- RMS 是对已有固定音频预计算的信号统计，不是推理模型。当前小样不包含流式音频输入、麦克风、ASR、LLM 或在线 TTS。

## 首版效果判断（原程序绘制角色，历史记录）

| 观察项 | A：2D | B：真人局部修改 |
|---|---|---|
| 嘴部与整体风格 | 简化画风中开合、收唇较协调，但仍夸张 | 张嘴时口腔轮廓、牙齿与原唇部的质感不一致 |
| 眼睛／皮肤／细小动作 | 动画痕迹明显，表情有限 | 原素材的眨眼、皮肤纹理更自然 |
| 中文准确性 | 使用估算时间，不能承诺准确对音素 | 同一估算时间，真实人物更容易暴露错位 |
| 素材适用性 | 绘制好的角色可复用 | 仅适配该素材；明显转头、嘴部遮挡与换人未验证 |
| 推荐 | 适合继续验证风格化虚拟助手 | 保留实验，不建议本版直接作为正式真人数字人 |

这是单一短句、单一人物素材、同一浏览器中的观察，不是两个技术路线的普遍效果排名。不能从该小样推导任意图片都可用、10 分钟稳定性、端到端对话延迟或多设备性能。
